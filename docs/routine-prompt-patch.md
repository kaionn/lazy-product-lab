# Routine prompt パッチ: 重複回避 + 却下フィードバック

> 対象: CCR routine `trig_016X45Gm7f2Ux6tj1gSs4y9r`（月水金 7:00 JST の 3 案生成）
> routine prompt には PAT がハードコードされているため、更新は claude.ai UI から手動で行う
> （Claude Code からの prompt 更新は classifier にブロックされる）。

## 適用方法

claude.ai → Routines → 該当 routine の prompt を開き、「3 案を生成する」指示の**直前**に以下のブロックを追記する。PAT やその他の既存記述は変更しない。

## 追記するブロック

```
## 生成前に必ず読むファイル (重複回避・負例参照)

3 案を考える前に、clone したリポジトリの以下 2 ファイルを読むこと:

1. `INDEX.md` — 過去に生成した全アイデアの一覧。
   ここに載っているものと同一・類似のアイデア (同じ痛みを同じ切り口で解くもの) は出さない。
   同じ痛みでも切り口が明確に異なるなら可。
2. `feedback/rejections.md` — 却下されたアイデアと却下理由のログ (存在する場合のみ)。
   これらは負例。同種の案や、却下理由に該当する案は出さない。

ファイルが存在しない・空の場合はこのステップをスキップしてよい。
```

## 検証

次回の生成実行後、candidates の 3 案が INDEX.md の既出案と被っていないことを確認する。
被りが続くようなら「類似」の判定基準を prompt 内でより具体化する
（例: 対象ユーザーとカテゴリが両方一致したら類似とみなす）。

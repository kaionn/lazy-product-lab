## 1. Ping or Die

- カテゴリ: SaaS
- 対象ユーザー: 個人サービスを運営するインディーハッカー・個人開発者
- 一行で: cron が死んでも3日後に気づく問題を終わらせる

### 解決する痛み

夜間バッチが無言で死んでいるのを3日後に発覚する。Better Uptime / Cronitor は設定が重くてオーバースペック。やりたいことは「指定時間内に curl が来なかったらメールを送る」それだけなのに、ダッシュボードを作らされてアカウント登録して Slack 連携して……で疲弊する。cron job や health check スクリプトの最後に `curl ping_or_die.io/abc123` の1行を足すだけで監視が完結してほしい。

### 1 週間で作るならこれ

- `POST /monitors` でモニター作成 → ユニークな ping URL を発行
- cron や healthcheck スクリプトから `curl https://ping-or-die.io/{token}` するだけで登録完了
- 設定インターバル内（5〜1440分）に ping が来なければメール通知
- シンプルダッシュボードで最終 ping 時刻・稼働状態を一覧
- 1ユーザー最大5モニター（ハードコード上限）

### なぜ雑か

Slack / PagerDuty 通知なしでメール一択。グラフ・メトリクス・ダウンタイム計算は一切なし。5モニター上限は設定値ではなくコードに直書き。無料枠オーバーの課金フローも実装しない（MVP は全部無料）。

### 雑な技術スタック候補

Bun + Hono + Turso (libsql/SQLite) + Resend (メール) + Railway でホスト

## 2. Nope Button

- カテゴリ: Browser Extension
- 対象ユーザー: ウェブサービス登録のたびにメール爆撃を受ける一般ユーザー
- 一行で: 「メルマガ購読」チェックを全自動で外してくれる拡張

### 解決する痛み

サービス登録フォームに最初からチェックが入っている「メールマガジン購読」「パートナー企業への情報提供」を毎回見落とす。チェックを小さく、ページの下の方に、グレー文字で配置する——ダークパターンは年々巧妙になっており、手動確認が追いつかない。登録後に解除しようとしたら「退会は郵送で」と書いてあって絶望する、あの体験をなくしたい。

### 1 週間で作るならこれ

- フォームにマウスオーバー or ページロード時に事前チェック済みチェックボックスを自動スキャン
- `newsletter`, `promotional`, `marketing`, `opt-in`, `メルマガ` 等のキーワードを含むラベルのものを自動解除
- ポップアップに「今日 N 個のチェックを自動解除しました」を表示
- 例外ドメインをホワイトリスト登録（銀行ログインなどで誤爆しないように）
- 右クリックコンテキストメニューから手動で「このチェックをブロック」

### なぜ雑か

キーワードマッチのヒューリスティックなので、ラベルが画像・独自テキストの場合は素通りする。GDPR/CMP 同意バナーは別物なので対象外。フォームが JS 動的生成の場合に MutationObserver の遅延で間に合わないことがある。Firefox 版は作らない。

### 雑な技術スタック候補

Chrome Extension Manifest V3 + TypeScript + Vite でビルド、Chrome Web Store に提出

## 3. Screamo.fm

- カテゴリ: Web
- 対象ユーザー: メタル・パンク・インディーロックのコアファンで新バンドを掘れなくなった人
- 一行で: 好きなバンド3つで地下アーティストを5件発掘するツール

### 解決する痛み

Spotify も Apple Music も「あなたへのおすすめ」がすでに知っているバンドばかり。アルゴリズムは再生数を優先するので有名バンドの周辺しか出てこない。本当に聴きたいのはリスナー数10万人未満のアンダーグラウンドバンドなのに、シーン内のコネがないと発見できない。Last.fm のタグを手動でたどる作業を自動化したい。

### 1 週間で作るならこれ

- バンド名を3つ入力 → Last.fm API でそれぞれの similar artists を取得・マージ
- リスナー数でフィルタ（1万〜10万のアンダーグラウンド帯）して重複除去
- 5バンドを推薦 → Bandcamp 検索リンク・Spotify 検索リンク・Last.fm タグ（ジャンル）を表示
- 「もっと掘る」ボタンで追加5件をロード（ページング）
- 推薦結果を URL パラメータで友達にシェア可能（`?bands=A,B,C`）

### なぜ雑か

推薦ロジックは Last.fm の similar artists API をそのままフィルタするだけで ML なし。Bandcamp / Spotify リンクはキーワード検索 URL なので実在保証なし（検索結果に別バンドが出る可能性あり）。日本語バンド名は Last.fm のデータ次第で失敗することがある。リスナー数の閾値は全ジャンル共通で調整不可。

### 雑な技術スタック候補

Next.js (App Router) + Last.fm API + Vercel (API Route で CORS 回避) + shadcn/ui で最低限の見た目

## 1. Startup Panic（スタートアップパニック）

- カテゴリ: ゲーム (Web)
- 対象ユーザー: 起業に興味があるエンジニア・サイドプロジェクト志向の社会人・学生
- 一行で: 12ターンでスタートアップを生き残らせる経営シム

### 解決する痛み

「採用するか・マーケに使うか・技術負債を返すか」の判断感覚を体験できるゲームがない。本格的な経営シム（Capitalism Lab 等）は重くて学習コストが高い。ビジネス書を読んでも「実際の判断」の感覚は身につかない。気軽に5分で1ゲーム終わって「あ、採用しすぎると資金が尽きるんだ」と体で覚えられる遊び場が欲しい。

### 1 週間で作るならこれ

- 初期予算・チームサイズを設定してゲーム開始
- 各ターンにランダムイベント（競合出現 / 大口顧客獲得 / エンジニア突然退職 / プレスリリース炎上 / VC面談）が1つ発生
- 3択の対応策を選ぶと予算・チーム・評判・技術的負債の4パラメータが増減
- 12ターン後にパラメータ状況でエンディング5種（大成功 / IPO / バイアウト / 倒産 / 細々継続）分岐
- ハイスコアを localStorage に保存してリプレイ性を出す

### なぜ雑か

バランス調整ほぼなし・パラメータ計算式は全部マジックナンバー。グラフィックは絵文字のみでアニメーションなし。イベントは40個ハードコードで組み合わせ考慮なし。BGMや効果音は実装しない。

### 雑な技術スタック候補

Vite + Vanilla TypeScript + GitHub Pages、サーバーレス完全無料・外部APIゼロ

## 2. USB Watt Logger

- カテゴリ: ハードウェア
- 対象ユーザー: デスク周りの電力消費が気になるガジェットオタク・省エネ意識の高い在宅ワーカー
- 一行で: 1200円で作るUSB電力ロガー、デバイス別消費電力を24hグラフ化

### 解決する痛み

モニター・充電器・照明など机周りのUSBデバイスが「実際にどれくらい電気を使っているか」全く分からない。Amazonのスマートプラグは2000円以上で細かい計測は難しく、USB電力計は測定するだけで記録が残らない。「スリープ中でも電気使ってるの？」という素朴な疑問に誰も答えてくれない。

### 1 週間で作るならこれ

- Raspberry Pi Pico W (900円) + INA219電流センサモジュール (300円) で電力測定回路を組む
- 5秒ごとに電圧(V)/電流(mA)/電力(mW)をシリアル経由でホストPCに送信
- ホスト側Pythonスクリプトが `power_log_YYYYMMDD.csv` に追記しながらターミナルにリアルタイム表示
- `python plot.py` で matplotlib の24時間折れ線グラフを PNG 出力
- 500mA 超えをターミナルに赤字アラート（過負荷検知の代わり）

### なぜ雑か

安物INA219センサの測定誤差は±5%以上。ケーブル加工は自己責任（感電・火災の免責だけ README に書く）。ログはCSVの垂れ流しでローテーションなし（長期運用でGBになっても知らない）。複数ポート同時計測は回路を自分で増設してほしいのだ。

### 雑な技術スタック候補

MicroPython (Pico W) + Python 3 + matplotlib on ホストPC、クラウド一切不要

## 3. JSON Diff Live

- カテゴリ: Web
- 対象ユーザー: APIのバージョン間の変化を追うバックエンドエンジニア・外部APIインテグレーターの開発者
- 一行で: JSONを2つ貼るだけで差分を色分け即表示するライブビューア

### 解決する痛み

APIレスポンスの変化確認に毎回 `jq . a.json | diff - <(jq . b.json)` を書くのが面倒。深いネストの中で何フィールドが増えたか把握するのに時間がかかる。レビュー中に「このPR、レスポンス形式変えてない？」を素早く確認したいのに、エディタの diff は JSON 整形を先にしないと使えない。パッと開いてパッと確認できるツールが欲しい。

### 1 週間で作るならこれ

- 左右2ペインにJSONをペーストすると即座に差分ハイライト（リアルタイム）
- 追加(緑)/削除(赤)/変更(黄)でキー・値を色分け表示
- JSONパスで「どこが変わったか」リスト表示（例: `$.user.address.zipcode` changed from "100-0001" to "150-0001"）
- 差分サマリ（追加N個・削除N個・変更N個）をページ上部に常時表示
- URLを入力してそのままfetchして比較（CORS非対応は諦めてもらう）

### なぜ雑か

認証なし・保存なし。配列の差分はインデックスベース比較のみで意味的な並び替え検知は完全無視。JSONが5MB超えるとブラウザが固まる可能性あり。CORSで詰まったURL fetchは自力解決してほしいのだ。

### 雑な技術スタック候補

Vite + React + jsondiffpatch ライブラリ + Tailwind CSS + Cloudflare Pages 無料枠

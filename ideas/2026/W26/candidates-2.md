## 1. BlameGame

- カテゴリ: ゲーム
- 対象ユーザー: コードレビュー文化を楽しくしたいチームエンジニア・チームリード
- 一行で: git blame で犯人当てクイズゲーム

### 解決する痛み

チームビルディングのアイスブレイクがマンネリ化していて、毎回「ではひとこと自己紹介を」で終わる。技術的負債がどこから来たのか言いにくい空気がある。コードレビューが義務感だけの場になっていて会話が生まれない。「このコード誰が書いたの？」は毎回笑いになるポテンシャルがあるのに、チームで一緒に遊べる形になっていない。

### 1 週間で作るならこれ

- ローカルの git リポジトリを指定してランダムに 20 行を抽出（著者名は伏せる）
- 4 択（リポジトリのコントリビューター一覧から自動生成）でターミナルに出題
- 正解・不正解を即フィードバック、全問終了後にスコア集計を表示
- 「最古コード保持者ランキング」を bonus で表示（`git log --follow` 使用）
- `--rounds 30` オプションで出題数を変更可能

### なぜ雑か

マルチプレイヤー機能なし（PC 1 台を回してプレイするスタイル）。マージコミット・bot コミット・1 行修正コミットも問題に混入する。大規模リポジトリはランダムサンプリングで代表性の保証なし。コミット著者が 1 人しかいないリポジトリで動かすと意味をなさない。

### 雑な技術スタック候補

Python + Click + Rich (ターミナル描画) + GitPython + PyPI 配布でインストール 1 コマンド

## 2. ClipNote

- カテゴリ: Browser Extension
- 対象ユーザー: 調査・リサーチ中にタブを大量に開く研究者・ライター・エンジニア
- 一行で: 選択テキストをURL付きで一発保存する拡張機能

### 解決する痛み

「あの記事のあの一文どこだっけ」でタブを 30 個遡って探し回る。いい文章をコピーしても、どのページから取ったか後から分からなくなる。Notion に貼ろうとするたびにウィンドウを切り替えるのが面倒で途中で諦める。リサーチ中は「今は読む」フェーズで「整理」フェーズに切り替えたくない。出典 URL と引用テキストをセットで手元に積んでいけるだけで十分なのに、それだけに特化したツールがない。

### 1 週間で作るならこれ

- テキストを選択 → 右クリック「ClipNote に保存」で URL + 選択テキスト + ページタイトル + 日時を即保存
- chrome.storage.local に全件保存（クラウド不要・アカウント不要）
- 拡張アイコンをクリックすると今日の引用一覧をポップアップ表示
- 「Markdown でエクスポート」ボタンで全件を `> 引用\n\n出典: URL` 形式のテキストとしてダウンロード
- 保存件数バッジをアイコンに表示

### なぜ雑か

テキスト選択のみ対応（画像・動画のスクラップなし）。タグ付け・フォルダ分け機能なし。検索機能なし（一覧スクロールのみ）。Firefox・Safari 未対応、Chrome 専用。保存件数が 1000 件を超えると古い順から消えるが警告なし。

### 雑な技術スタック候補

Vanilla JS + Chrome Extension Manifest V3 + chrome.storage.local + Blob API (エクスポート用)

## 3. FocusCast

- カテゴリ: デスクトップアプリ
- 対象ユーザー: BGM を流しながら作業するが選曲に集中を奪われがちな在宅ワーカー
- 一行で: タスク種別を選んだらBGMとタイマーが連動して自動で動く

### 解決する痛み

Spotify の Lo-Fi プレイリストが途中で終わって沈黙に気づいて集中が切れる。「次の曲どうしよう」の選曲 30 秒でフロー状態が消える。ポモドーロタイマーと音楽が連動していないので休憩中も集中 BGM が流れ続けておかしい。作業の種類（深い集中 / 軽い事務 / 休憩）で BGM を切り替えたいが手動でやるのが面倒。タイマーアプリと音楽プレイヤーを別々に管理するのが地味にストレス。

### 1 週間で作るならこれ

- 作業タイプを 3 種類から選択（深い集中 25 分 / 軽作業 15 分 / 休憩 5 分）
- ローカルフォルダを指定して mp3 をシャッフル再生、タイマーと完全連動
- タイマー終了 30 秒前から音量を自動フェードアウト、セッション終了を通知
- 次セッションへのカウントダウン表示と自動遷移
- タスクタイプごとに画面の背景色が変わる（視覚的に状態を把握できる）

### なぜ雑か

ストリーミング非対応、ローカル mp3 のみ。mp3 ファイルは自分で揃えてもらう前提（著作権的に同梱不可）。クロスフェードなし・曲が途切れる瞬間がある。スマホ連携なし。タスクログ保存機能なし（今日何ポモドーロやったかは自分で数える）。

### 雑な技術スタック候補

Electron + React + Howler.js (音声再生) + electron-store (設定保存) + electron-builder でインストーラ配布

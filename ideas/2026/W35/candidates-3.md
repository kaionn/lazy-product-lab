## 1. ぐるぐるインポート探偵

- カテゴリ: CLI
- 対象ユーザー: JS/TS/Pythonの中規模〜大規模リポジトリを触るエンジニア
- 一行で: import文を静的解析するだけで循環インポートの経路を一覧にしてくれるのだ

### 解決する痛み

実行時に原因不明の `undefined` エラーが起きて、追ってみたら循環インポートが原因だったという経験は誰にでもある。特にリファクタ中にファイルを跨いでimportし合う設計になり、気づかず本番でクラッシュする。ESLintのプラグインや専用の依存解析ツールは導入自体にプロジェクト設定が必要で重く、今すぐ「このファイルとこのファイルがお互いを呼んでるよ」だけをサクッと知りたい場面には合わない。npxで一発叩いて答えだけ欲しい。

### 1 週間で作るならこれ

- エントリーポイントのディレクトリを指定するとファイル一覧を再帰的にスキャン
- import/require文を正規表現ベースで抽出してファイル間の依存グラフを構築
- グラフ内の閉路をDFSで検出してリストアップ
- 閉路に含まれるファイル数が多い順にランキング表示
- 見つかった閉路をターミナルに矢印付き（A→B→C→A）で出力

### なぜ雑か

TypeScriptのpath alias（tsconfig paths）解決は素朴な相対パスのみ対応で複雑なalias設定は無視する。動的`import()`やrequireの条件分岐は解析対象外。モノレポのpackage境界をまたぐ循環は検出しない。型のみのimportによる誤検知を除外するロジックは持たない。

### 雑な技術スタック候補

Node.js + TypeScript + acorn（簡易AST解析）+ 自前DFS実装 + chalk（色付け出力）+ npm packageとしてnpx実行可能に

## 2. 離席うっかりロック番

- カテゴリ: デスクトップアプリ
- 対象ユーザー: カフェやコワーキングスペースで作業する人、オフィスでうっかり離席しがちな人
- 一行で: 席を離れた瞬間をWebカメラが検知してロック画面忘れをそっと知らせてくれるのだ

### 解決する痛み

トイレや給湯室にちょっと立つとき、いちいちロックショートカットを押すのが面倒でつい忘れる。カフェで画面点けっぱなしのまま離席して戻ったら隣の人にタブを覗かれていた気まずさもある。会社のセキュリティ研修で「離席時は必ずロック」と言われても習慣化できていない人は多い。強制ロックまでは要らないが、離席に気づいて念押ししてほしいだけ。

### 1 週間で作るならこれ

- 常駐アプリがWebカメラから1〜2秒おきに顔検出のみ実行（誰かの特定はしない）
- 顔が画面前から一定秒数（設定可、デフォ15秒）消えたら通知音+デスクトップ通知を表示
- 通知後さらに一定秒数放置されたらOS標準のロックコマンドを自動実行
- タスクトレイに簡易オン・オフトグルとしきい値設定
- 顔検出結果はメモリ上のみで保存せず即破棄

### なぜ雑か

顔検出は正面向きのみ想定で、横顔や暗い部屋では誤検知が多発する。複数人が映る共有デスクでは常に「誰かいる」と判定されがち。マルチモニタ環境でのカメラ配置は考慮しない。誤動作でロックされても解除は通常のOSパスワード入力任せで、専用の解除UIは作らない。

### 雑な技術スタック候補

Electron + face-api.js（ブラウザ内顔検出、クラウド送信なし）+ OS標準ロックコマンド呼び出し（macOS: pmset displaysleepnow / Windows: rundll32 user32.dll,LockWorkStation）

## 3. 言った言わない防止くん

- カテゴリ: Bot (Discord)
- 対象ユーザー: 小規模チームで議事録係を置く余裕がないスタートアップ・受託チーム
- 一行で: 会議メモを貼るだけで「誰が何をいつまでにやると言ったか」を抽出して未完了なら催促してくれるのだ

### 解決する痛み

会議中に「じゃあ〇〇さんお願いします」で決まった作業が、議事録に残らずそのまま忘れられていく。次の会議で「あれどうなった?」と聞かれて初めて誰も着手していないことが発覚する。決定事項をログとして残す仕組みはあっても、担当者・期限つきのタスクとして追跡し完了を催促する仕組みは別物として抜け落ちがち。会議メモをそのまま貼るだけで済ませたい。

### 1 週間で作るならこれ

- Discordの特定チャンネルに会議メモ（箇条書きテキスト）を貼るとAIが「担当者・タスク内容・期限」を抽出
- 抽出結果をボットが表形式で即座に返信、リアクション✅で完了マーク可能
- 期限当日の朝に未完了タスクだけを担当者宛にメンションしてリマインド
- 期限を過ぎても未完了なら次の会議の朝に「持ち越しタスク」として一覧再掲
- タスクの手動追加・編集フォームは用意しない（貼り付けと✅のみ）

### なぜ雑か

担当者名はDiscordの表示名との完全一致でしか紐付けず、あだ名や誤字は拾えない。期限の自然言語解析は「明日」「来週」程度の単純パターンのみ対応。1メッセージあたりの抽出タスク数上限は20個まで。タスクの優先度や依存関係は一切扱わない。

### 雑な技術スタック候補

Discord.js + OpenAI API（構造化出力でタスク抽出）+ Supabase（タスク保存・期限チェック）+ Vercel Cron（毎朝のリマインド起動）

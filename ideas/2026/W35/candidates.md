## 1. ロックファイル多重人格検査官

- カテゴリ: CLI
- 対象ユーザー: 複数パッケージ/ワークスペースを持つモノレポでnpm/yarn/pnpmを使うエンジニア
- 一行で: package.jsonとlockfileを渡すだけで同じライブラリの複数バージョン混在を一覧にしてくれるのだ

### 解決する痛み

モノレポで各ワークスペースが独自にreactやlodashのバージョンを指定してしまい、bundleサイズが膨らんだりworkspace間で型不整合が起きる。誰も意図的にやっているわけではなく、気づかないまま積み重なる。手動でlockfileを開いてバージョンを目grepするのは苦痛だし、レビューでも見落とされがち。CIで自動的に「重複してるよ」と教えてくれれば十分。

### 1 週間で作るならこれ

- pnpm-lock.yaml をパースするパーサーを実装（まずpnpmのみ対応）
- パッケージ名ごとに検出されたバージョン一覧とどのworkspaceが使っているかをマッピング
- 2つ以上の異なるメジャーバージョンが混在するパッケージをハイライトしてテーブル出力
- `--json` オプションでCIに食わせられる出力もサポート
- 重複が多い順にソートして上位10件をターミナルにカラー表示

### なぜ雑か

対応するパッケージマネージャはpnpmのみ（yarn/npmは後回し）。メジャーバージョンの互換性判定はしない（数字が違うだけで警告扱い）。peerDependenciesの警告とは連携しない。pnpm-workspace.yamlの複雑なglobパターンは簡易対応のみ。

### 雑な技術スタック候補

Node.js + @pnpm/lockfile-file + commander (CLI) + chalk (色付け) + cli-table3

## 2. 水分補給リマインドコースター

- カテゴリ: ガジェット
- 対象ユーザー: 集中すると水を飲むのを忘れて気づいたら頭痛がしているデスクワーカー
- 一行で: マグカップを置くだけで一定時間持ち上げてないとコースターがやんわり光って教えてくれるのだ

### 解決する痛み

作業に没頭すると水分補給を忘れ、気づいたら頭が痛い・集中力が落ちている。スマホの水分補給アプリは通知を出しても結局スワイプして終わりで習慣にならない。目の前に置いてあるコースターがふと光れば、視界に入るぶん無視しにくい。デスクに置くだけで生活を変えずに始められるのが良い。

### 1 週間で作るならこれ

- ESP32 + 重量センサー(ロードセル)をコースター型ケースに内蔵
- コップが持ち上げられた（重量が閾値以下になった）タイミングを検知してタイマーリセット
- 45分間持ち上げられていなかったらLEDリングがゆっくり点滅開始
- 90分放置でLEDが早い点滅+ブザーへ格上げ
- 3Dプリントかレーザーカットの簡易ケースに収める（見た目は二の次）

### なぜ雑か

水以外の飲み物（コーヒー等）と区別しない。複数人・複数コースターの管理機能なし（1台のみ動作確認）。夜間モードなし（24時間監視され続ける）。重量センサーのキャリブレーションは起動時に自動で1回だけ行い、途中でコップの種類を変えると誤検知しうる。

### 雑な技術スタック候補

Arduino IDE + ESP32 + HX711 (ロードセル用ADC) + NeoPixel LEDリング + 圧電ブザー

## 3. 会議脱線アラート

- カテゴリ: Web (AI ツール)
- 対象ユーザー: 定例会議のファシリテーターで議題から脱線しがちなチームを持つ人
- 一行で: 会議の文字起こしをリアルタイムで流し込むだけでアジェンダから脱線した瞬間にアラートしてくれるのだ

### 解決する痛み

会議のアジェンダを事前に決めても雑談や別件の話に脱線して時間切れになることが多い。ファシリテーターが「それ今関係ないですよね」と本人の口から言い出しにくい雰囲気があるチームも多い。議事録係が後から気づいても手遅れ。第三者的に「今アジェンダの何%を消化しましたか」と機械的に教えてくれると、指摘のハードルが下がる。

### 1 週間で作るならこれ

- 会議開始前にアジェンダ項目をテキストで箇条書き登録する画面
- ブラウザのマイクから音声を取得し、Whisper APIで30秒ごとにバッチ文字起こし
- 直近の文字起こしテキストと各アジェンダ項目の関連度をLLMに判定させる
- どのアジェンダ項目にも該当しない発言が3回連続したら画面に「脱線中かも」バナー表示
- 会議終了後にアジェンダ項目ごとの推定所要時間を簡易グラフで表示

### なぜ雑か

話者分離はしない（誰が言ったかは記録しない）。日本語以外の言語は未対応。文字起こしは30秒バッチのため厳密なリアルタイムではない。誤判定（実は関連している発言をズレていると判定）への異議申し立て機能はない。録音データはセッション終了後に保存せず捨てる。

### 雑な技術スタック候補

Next.js + MediaRecorder + OpenAI Whisper API + GPT-4o-mini (関連度判定) + Vercel

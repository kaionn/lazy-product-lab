## 1. デジャブエラー番人

- カテゴリ: Browser Extension
- 対象ユーザー: 同じエラーを何度もググっては忘れているエンジニア
- 一行で: 選択したエラーメッセージが過去に検索済みなら「前にも見た」と教えてくれるのだ

### 解決する痛み

同じスタックトレースやエラーメッセージを半年に一度くらいの頻度で検索してしまい、以前どう解決したか思い出せず一から調べ直すことがよくある。過去の解決メモはSlackのDMやメモ帳に散らばっていて検索性がなく、「あのエラーいつ調べたっけ」から探し始めるのは苦痛。ブラウザの閲覧履歴を漁ってもキーワードを覚えていなければ辿り着けない。エラーらしき文字列を選択するだけで「これ前にも検索してますよ」と警告してくれれば、過去のメモにすぐ飛べる。

### 1 週間で作るならこれ

- テキスト選択時に正規表現でエラーメッセージらしい文字列（`Error:` `Exception` スタックトレース風の行など）を検出
- 検出した文字列のハッシュを取り、検索日時・ページタイトルとともに `chrome.storage.local` に記録
- 同じ・類似ハッシュを再度選択したときに「前回 YYYY-MM-DD に見てます」と小さなトースト表示
- トーストから当時つけた一言メモを確認・追記できる簡易ポップアップ
- 記録した全エラーをオプションページで検索・削除可能な一覧表示

### なぜ雑か

類似度判定は編集距離ベースの簡易マッチのみで、変数名や行番号が変わると別エラー扱いになりうる。複数端末間の同期はなし（ローカルストレージのみ、他PCでは別履歴として積み上がる）。エラーらしき文字列の検出は英語パターン中心の正規表現に依存し、日本語エラーメッセージは拾いにくい。メモを書かなくても記録自体は溜まる仕様なので空メモだらけになりがち。

### 雑な技術スタック候補

Chrome Extension (Manifest V3) + chrome.storage.local + 簡易Levenshtein距離ライブラリ + Vanilla JS

## 2. カチャカチャ番人

- カテゴリ: ガジェット
- 対象ユーザー: オープンオフィスや薄い壁の自宅で在宅勤務し、自分のタイピング・マウスクリック音が周囲の迷惑になっていないか気になるエンジニア
- 一行で: マイクを置くだけでタイピング音が一定の大きさを超えたらそっとLEDで教えてくれるのだ

### 解決する痛み

オープンオフィスや家族と同居しながらの在宅勤務では、自分では気づかないうちにキーボードやマウスの操作音が周囲の迷惑になっていることがある。同僚や家族から直接「うるさい」と言われる前に自分で気づきたいが、常に音量を意識しているわけにもいかない。指摘されないまま我慢されているだけかもしれないという不安もついて回る。目の前で静かに光るランプが唯一のフィードバックなら、指摘される気まずさなしに自分で調整できる。

### 1 週間で作るならこれ

- ESP32 + コンデンサマイクモジュール（MAX9814等）で周囲の音量（相対値）を常時計測
- 直近10秒間の音量ピークが閾値を3回以上超えたらLEDがゆっくり黄色点灯
- さらに超過が続く（1分間で10回以上）とLEDが赤に変化
- 閾値超えのない状態が5分続いたらLEDは自動で消灯しリセット
- ローカルWebページ（mDNS経由）で閾値の感度を調整可能

### なぜ雑か

音量計測はdB絶対値ではなくマイクのアナログ出力に基づく相対閾値判定で、環境ごとに手動キャリブレーションが必要。誰の音か（自分か周囲の音か）は区別できず置き場所に結果が依存する。音声データ自体は録音・保存しない。複数人分の判定や履歴グラフ化はスコープ外で、光るランプ1個のみで完結させる。

### 雑な技術スタック候補

Arduino IDE + ESP32 + MAX9814マイクモジュール + NeoPixel LED + WebServerライブラリ（閾値設定用）

## 3. 名刺、放置してませんか

- カテゴリ: モバイル (PWA)
- 対象ユーザー: 展示会や勉強会で名刺交換はするもののフォローアップメールを送りそびれがちな営業・エンジニア
- 一行で: 名刺を撮るだけで3日後にまだ連絡してなければそっとリマインドしてくれるのだ

### 解決する痛み

イベントや勉強会で名刺交換をした直後は「今度お茶しましょう」で盛り上がるが、名刺は財布やカバンの中に沈み、気づけば誰と何を話したかも思い出せなくなる。名刺管理アプリはデータ化はしてくれるが、フォローアップを送ったかどうかまでは追跡してくれない。結局「あの人にお礼メール送ったっけ」を自分の記憶だけに頼ることになり、送りそびれたまま関係が自然消滅する。撮った瞬間にカウントダウンが始まれば忘れにくい。

### 1 週間で作るならこれ

- カメラで名刺を撮影し、氏名・会社名・出会った日を登録（OCR自動読み取り、失敗時は手入力）
- 登録と同時に「フォローアップ済み」チェックボックス付きカードをタイムラインに追加
- 登録から3日後にチェックが付いていなければプッシュ通知で「まだ連絡してません」とリマインド
- カードをタップして「話した内容」を1行だけ追記できるメモ欄
- 全カードを未フォロー/フォロー済みでフィルタして一覧表示

### なぜ雑か

OCR精度は割り切ってML Kit等にそのまま投げるだけで、誤読の手動修正が前提。名刺画像自体の整理機能（裏面・複数枚一括撮影など）は作らない。フォロー手段（メール/LINE等）がどれだったかは記録せず、チェックの有無だけを見る。リマインドは登録3日後の1回のみでスヌーズ機能はない。

### 雑な技術スタック候補

React Native (Expo) + expo-camera + ML Kit Text Recognition + expo-notifications + AsyncStorage（ローカル保存のみ）

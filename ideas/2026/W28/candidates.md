## 1. LunchDebt Tracker

- カテゴリ: Bot (Slack)
- 対象ユーザー: 日常的にランチや飲み物を代払いし合うオフィスチーム・友人グループ
- 一行で: 奢り奢られをBotに記録して月末精算を自動計算

### 解決する痛み

同僚とランチを交互に奢り合っているが、誰が何回・何円払ったかの記憶が曖昧になりがち。「あれ、最近オレだけ払ってないか？」というモヤモヤが積み重なる。LINE に「次よろしく」と送っても流れて忘れる。月末に「誰に何円払うべきか」を手で集計するのは面倒すぎて省略され、なんとなく不満だけが残る。

### 1 週間で作るならこれ

- `@lunchbot 田中に800円` で即記録（「に」「から」で貸し/借りを自動判定）
- `@lunchbot 残高` で自分の貸し借り一覧をスレッドに返信
- `@lunchbot 精算 田中` で田中との取引を清算済みマーク
- 月末 (毎月末日 AM9:00) にチャンネルへ全員の残高サマリーを自動投稿
- Vercel KV (Redis) で残高を永続化、Vercel Serverless Function でホスト

### なぜ雑か

OAuth フロー未実装 ─ 自チームのワークスペースへ手動インストールのみ対応。「500円だか600円だか忘れた」というあやふや記録は本人の責任。3人で均等割りするスプリット計算は未対応。エラーメッセージは「よくわからんのだ、もう一度試して」の一言で済ます。

### 雑な技術スタック候補

Node.js + Bolt for JS (Slack SDK) + Vercel Serverless Functions + Vercel KV (Redis)

## 2. 時給フィルター

- カテゴリ: Browser Extension (Chrome)
- 対象ユーザー: ネットショッピングで衝動買いしがちな節約意識のある社会人
- 一行で: ページ上の価格を全部「時間」に換算して表示する

### 解決する痛み

¥29,800 のモニターが「高い」か「安い」か、感覚だけで判断してしまう。「時給に直せば?」と毎回頭をよぎるが手計算する気が起きず、結局感情のままポチる。後でレシートを見て後悔するサイクルが止まらない。「あと 17 時間働いた分か」とリアルタイムで見えれば、衝動買いのブレーキになるはず。

### 1 週間で作るならこれ

- 拡張の設定画面で「時給」または「月収 ÷ 営業時間」を入力して chrome.storage.sync に保存
- Amazon JP・楽天・価格.com の価格要素の隣に「≒ X 時間 Y 分の労働」を青文字で自動追記
- Twitter/X のタイムライン中の「¥XX,XXX」形式の文字列も変換対象
- 計算根拠をホバーで表示（「時給 1,500 円 × 19.87 時間」）
- 拡張アイコンをクリックして換算 ON/OFF をワンクリックで切り替え

### なぜ雑か

DOM 監視は MutationObserver を使わず setInterval でポーリング ─ 重い。Amazon の動的価格ロード後にズレることがある。Firefox・Safari 非対応。月額サブスクの「月 ¥980」は月間労働時間に換算せず、そのまま時給割りするだけ。マイナス表示（ポイント値引き）は未対処でおかしな数字が出ることがある。

### 雑な技術スタック候補

Chrome Extension Manifest V3 + Vanilla JS content script + chrome.storage.sync（ビルドツール不使用、zip 直配布）

## 3. VoiceMemo2md

- カテゴリ: デスクトップアプリ (macOS / Windows)
- 対象ユーザー: 散歩中・作業中にアイデアが浮かんでもスマホを出せないエンジニア・クリエイター
- 一行で: ホットキー一発で録音しWhisperで文字起こしmdに保存

### 解決する痛み

移動中や両手が塞がっているときにアイデアが浮かんでも、スマホ取り出す → アプリ起動 → 録音 → 後でテキスト化、という手順が面倒で「まあいいか」と流してしまう。後で聞き返すコストが高くて音声メモが死蔵される。テキスト化されていれば Obsidian や Notion に取り込めるのに、録音ファイルは永遠に聞かれないまま積まれ続ける。

### 1 週間で作るならこれ

- グローバルホットキー（Ctrl+Shift+V）でシステムトレイから即録音開始 / 停止
- 停止後、Whisper.cpp tiny モデルをローカル実行して自動文字起こし（オフライン・API コスト不要）
- `~/voice-memos/2026-07-10-1430.md` にタイムスタンプファイル名で保存
- システムトレイアイコンが「録音中（赤）」「文字起こし中（黄）」「完了（緑）」で状態を色表示
- トレイメニューから直近 5 件のメモタイトルをプレビュー表示

### なぜ雑か

Whisper tiny モデルは精度が低く、専門用語・固有名詞・英語混じりの発言は誤変換される。句読点はほぼ出力されず、読点ポイントが適当。Windows での動作確認は最低限（開発は macOS 優先）。長時間録音（5 分超）はメモリが怪しい。ファイル名が同分内に複数録音すると衝突する。

### 雑な技術スタック候補

Electron + whisper-node (whisper.cpp の Node.js バインディング) + node-global-key-listener、macOS .dmg と Windows .exe で配布

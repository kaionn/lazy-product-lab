## 1. LINEペット健康ノート

- カテゴリ: Bot (LINE)
- 対象ユーザー: 犬猫を飼っている一人暮らし・夫婦・シニア
- 一行で: LINEに「散歩20分」と送るだけで記録が積まれる

### 解決する痛み

ペット専用アプリを落とした初日だけ記録してその後放置、という体験が繰り返される。「アプリを開く」という動作が習慣に刺さらない。でも LINE は毎日開く。体重・食欲・ワクチン接種日を後から動物病院に正確に伝えられなくて困る瞬間が必ず来るのに、記録がどこにも残っていない。

### 1 週間で作るならこれ

- 「体重 3.2kg」「散歩 30分」「ワクチン 狂犬病」などの自然語を LINE に送ると自動分類して SQLite に記録
- 「今週のまとめ」と送ると体重推移・散歩時間・食事量を集計して返信
- ワクチン記録から 11 ヶ月後に「来月ワクチンの時期ですよ」とリマインド
- 複数頭は「タロウ 体重 5kg」のように名前プレフィックスで管理
- 「CSV」と送ると全記録を TSV テキストで返信（動物病院に渡す用）

### なぜ雑か

自然語解析はキーワードマッチのみ、認識できない入力は「わからなかった」と返すだけ。複数飼い主でのアカウント共有なし。LINE Messaging API 無料枠 1000 通/月を超えると止まる。グラフや画像は出さずすべてテキスト返信。

### 雑な技術スタック候補

Python + Flask + LINE Messaging API (Messaging SDK) + SQLite + Railway 無料枠

## 2. ZiNE Maker

- カテゴリ: Web
- 対象ユーザー: ZiNE・同人誌を印刷所に入稿したいイラストレーター・同人作家
- 一行で: トンボ付き入稿 PDF をブラウザだけで作れるレイアウター

### 解決する痛み

InDesign は月 2,728 円かかる。Canva は入稿に必要なトンボ（塗り足し 3mm）が出ない。「テキストと画像を並べた A5 PDF」を作りたいだけなのに Adobe 税を払い続けるのが辛い。パワポでデザインして「なぜかズレる」PDF を印刷所に送って怒られた経験は多くの同人作家に刺さる。

### 1 週間で作るならこれ

- A5 / B6 サイズ選択、表紙・本文ページの追加・削除・並べ替え
- テキストブロック・画像ブロックをキャンバスにドラッグ配置、サイズ変更
- Google Fonts から 8 種類の和文フォント選択（M PLUS / Noto Sans JP 等）
- jsPDF でトンボ（3mm 塗り足し・トンボマーク付き）PDF を出力
- プロジェクトを JSON でブラウザ保存（localStorage）してセッション跨ぎで続きから

### なぜ雑か

フォント埋め込みはブラウザ依存で印刷所によってはアウトラインに変換が必要。画像圧縮なし（大きな JPEG を入れると PDF が重くなる）。本文の自動テキスト流し込みなし。モバイルタッチ操作非対応。Fabric.js のバージョン差異で動かない環境があるかも。

### 雑な技術スタック候補

Vanilla JS + Fabric.js (Canvas操作) + jsPDF + Google Fonts API、GitHub Pages で静的ホスト・ビルド不要

## 3. GitBar

- カテゴリ: デスクトップアプリ
- 対象ユーザー: コーディング量を可視化したい個人開発者・副業エンジニア
- 一行で: メニューバー常駐でその日のコミット数と差分行数を表示するだけ

### 解決する痛み

「今日どれくらいコード書いたっけ」をターミナルを開かずにさっと確認したい。WakaTime は月課金、GitHub の草グラフは翌日反映で今日のリアルタイム状況が見えない。「コミットがたまったぞ」という達成感をゲームのスコアのように常時表示したい。

### 1 週間で作るならこれ

- macOS メニューバーに「⬆3 +234 -89」を 5 分ごとに自動更新して表示
- クリックするとポップアップで今日のコミット一覧（メッセージ・時刻・diff 行数）
- 設定画面で監視対象の git リポジトリを複数登録（全リポジトリを集計）
- 日付が変わると 0 リセット、昨日のサマリーをトースト通知で表示
- ポップアップ下部に「今週の累計」も小さく表示

### なぜ雑か

macOS 専用（Windows は未対応）。リポジトリが git init されていないフォルダを設定すると表示が「---」で止まる。メニューバー文字幅はハードコードで環境によって切れる。リモートへの push 有無は無視して local commit を数える。Electron は起動が重い。

### 雑な技術スタック候補

Electron + simple-git + React (ポップアップUI) + electron-menubar、GitHub Releases で DMG 配布

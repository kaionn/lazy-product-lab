## 1. レシートスナップ家計簿

- カテゴリ: モバイル
- 対象ユーザー: 家計管理したいが手入力が続かない一人暮らし社会人
- 一行で: レシートを撮るだけで今月の支出が見えるのだ

### 解決する痛み

マネーフォワード等のアプリは銀行連携の初期設定が重くて離脱する。現金払いのコンビニ・スーパー・飲食店は家計簿に乗らない穴になりがち。手入力は3日で挫折する。かといってレシートを財布に溜めてまとめて入力するライフスタイルは続いたためしがない。「撮ったら終わり」だけ実現したい。

### 1 週間で作るならこれ

- カメラでレシートを撮影 → Google Cloud Vision API (OCR) で文字認識
- 店名・合計金額・日付を正規表現で抽出してフォームに事前入力
- 「食費 / 交通 / 日用品 / 外食 / その他」5カテゴリに手動で確定するだけのシンプル操作
- 月次合計を棒グラフ（カテゴリ別）で表示
- 全データを CSV エクスポートするボタン

### なぜ雑か

手書きレシート・感熱紙の色落ちは認識失敗NGで手入力に落とす。品目単位の分類なし（レシート1枚を1カテゴリに強制マッピング）。外貨・海外レシート非対応。ローカルSQLiteのみでクラウド同期なし。金額が正しく取れなかったときの修正UIが雑（テキストフィールド1個だけ）。

### 雑な技術スタック候補

React Native (Expo) + expo-camera + Google Cloud Vision API + expo-sqlite + Victory Native（グラフ）

## 2. 見積モリ

- カテゴリ: 業務ツール
- 対象ユーザー: Excel で見積書を毎回ゼロから作るフリーランス・副業エンジニア
- 一行で: 工数と単価を入れたら見積PDFが30秒で出るのだ

### 解決する痛み

Excelの罫線が印刷時にズレる。毎回「前回のファイルどこだっけ」からスタートする。freee・マネーフォワードは機能が多すぎて見積書1枚出すのに初期設定30分かかる。月額課金のSaaSを見積書ためだけに契約するコスパが悪い。クライアントに送るたびにバージョン管理がカオスになる（見積書_v3_最終_修正2.xlsx 問題）。

### 1 週間で作るならこれ

- フォームに「クライアント名・自社名・作業名・単価・工数・支払い期限・備考」を入力
- 消費税10%を自動計算して税抜・税込金額を表示
- A4縦のPDFを生成してワンクリックでダウンロード
- 見積番号を自動採番（見積-2026-001 形式）で重複なし管理
- 過去5件の見積を localStorage で保存して「前回から複製」ボタンで再利用

### なぜ雑か

テンプレートは1種類固定でロゴ・フォント・色変更不可。電子署名なし。インボイス登録番号は備考欄に手書きで追記してもらう想定。複数明細行への対応はMVPスコープ外（1作業1行のみ）。印刷余白の微調整は不可。

### 雑な技術スタック候補

Next.js + @react-pdf/renderer + Tailwind CSS + localStorage + Vercel 無料枠

## 3. デスクエアモニター

- カテゴリ: ガジェット
- 対象ユーザー: 在宅で集中力の波が激しいと感じているリモートワーカー
- 一行で: 机の CO2 濃度を測って「換気しどき」を光で教えるのだ

### 解決する痛み

室内の CO2 濃度が 1000ppm を超えると集中力・認知機能が落ちると知っているが測定する手段がない。なんとなく午後3時に頭がぼーっとするのが「空気のせい」なのか「睡眠不足」なのか分からない。窓を開けるタイミングが完全に勘頼み。市販のCO2モニターは5000円〜で、データをPCで見られないものが多い。

### 1 週間で作るならこれ

- M5StickC Plus（約2000円）+ MH-Z19B CO2センサー（約1500円）をUART接続で配線
- M5StickC の液晶に現在の CO2 濃度（ppm）・温度・時刻を大きく表示
- 段階的ステータス: 700ppm未満（緑・快適）/ 1000ppm未満（黄・注意）/ 1000ppm以上（赤・換気せよ）で画面色変化
- `http://deskair.local/` で過去12時間の CO2 推移グラフをブラウザで確認
- 1000ppm を超えたら液晶が5秒おきにフラッシュしてアラート

### なぜ雑か

PM2.5・湿度・VOCは計測しない（MH-Z19BはCO2専用）。Wi-Fi環境必須でオフライン動作なし。電源はUSB-C固定でバッテリー搭載なし。センサーは起動から30分のウォームアップが必要で最初のデータは不正確。BLE / Homebridge連携なし。

### 雑な技術スタック候補

Arduino C (M5StickC SDK) + M5Unified + ESPAsyncWebServer + Chart.js（ブラウザ側）+ LittleFS でデータ保存

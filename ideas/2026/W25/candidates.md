## 1. ScopeCreep Detective

- カテゴリ: SaaS
- 対象ユーザー: 月5〜10クライアントを抱えるフリーランスエンジニア・デザイナー
- 一行で: チャット貼るだけでスコープ爆発を可視化するのだ

### 解決する痛み

「ちょっとこれも追加で」の積み重ねで当初2週間の仕事が2ヶ月に膨れ上がる問題。メールやSlackの文面を遡って「いつ何が追加されたか」を証明するのが面倒だし、クライアントに追加工数の請求根拠を示せないことが多い。Notionで議事録を毎回書くほどではないが、口頭・チャットで合意した追加要件がどんどん溜まっていく。

### 1 週間で作るならこれ

- プロジェクト作成: 当初仕様書のテキストを貼り付けて「ベースライン」として保存
- 追跡フェーズ: その後のチャット・メールを時系列で貼り付け（何度でも追加可）
- Claude API で「当初仕様に含まれない要件」を自動検出してリスト化
- 各追加要件に「工数ラフ見積もり（h）」を手動入力する欄
- 「追加作業確認メールの文面」を自動生成してコピーボタンで即コピー

### なぜ雑か

Slack/メール API 連携なし（コピペのみ）。工数見積もりは自己申告で自動計算はしない。日本語専用でプロジェクトデータは localStorage に保存するのでブラウザクリアで消える。Claude の誤検出（本当は当初仕様なのに追加扱い）は保証しない。

### 雑な技術スタック候補

Next.js + Claude Haiku API + localStorage（DBなし） + Vercel 無料枠

## 2. ExpLog Diff

- カテゴリ: CLI
- 対象ユーザー: ローカルで機械学習実験を回すデータサイエンティスト・ML エンジニア
- 一行で: 実験ログ2本をdiffして精度変化を色付きで瞬時に確認

### 解決する痛み

MLflow や WandB を入れるほどじゃない小規模実験で「昨日の実験より精度が上がったのか下がったのか」を確認するためにログファイルを2つ開いてスクロールして目視比較している。`epoch 50 val_loss: 0.234` と `epoch 50 val_loss: 0.198` を見比べるのが地味に辛い。grep で抽出しても並べ方が分からない。WandB を導入しようとしたら会社のセキュリティポリシーで使えなかった、というケースにも刺さる。

### 1 週間で作るならこれ

- `explog diff run1.log run2.log` で数値メトリクスを自動抽出
- `key: value` / `key=value` / JSON 行 の3パターンを正規表現でパース
- 共通キーの数値をターミナルに並べて差分（↑↓%と絶対差）を色付きで表示
- `--plot` フラグで epoch 推移を ASCII グラフで表示
- 複数ファイルを一括比較して最良実験（指定メトリクス基準）に ★ マーク表示

### なぜ雑か

カスタムフォーマット（独自ロガーの出力）は対応外で固定パターンのみ。TensorBoard / WandB の独自バイナリ形式は無視。GPU メモリ・時間などシステムメトリクスは別途確認してね、のスタンス。ネストした JSON は展開しない。

### 雑な技術スタック候補

Python + Click + rich（ターミナル出力・色付き） + plotext（ASCII グラフ）、pip install で配布

## 3. PlotHole Detective

- カテゴリ: ゲーム
- 対象ユーザー: 趣味で二次創作・オリジナル小説を書くアマチュア作家
- 一行で: 自分の小説をAIに詰問されてプロットの穴を発見するゲーム

### 解決する痛み

自分で読み返しても「これで合ってるか」が分からない。友人に読ませると「気にならなかった」と優しくスルーされる。プロ編集者がいないとプロットの矛盾を鋭く指摘してもらえない。書いたものに自信が持てなくて投稿をためらっている——というアマチュア作家あるある。

### 1 週間で作るならこれ

- あらすじ・章立て・キャラクター設定をテキストで貼り付け（〜3000字想定）
- Claude API が「鋭い一般読者」として「第2章でXが言っていたのに第5章でYというのは矛盾では？」形式の質問を15問順番に出題
- 各質問に対して「意図的な伏線 / 矛盾している / 気づかなかった」を選択
- 「矛盾している」「気づかなかった」を選んだ箇所を修正メモリストとして出力
- スコア（問題なし / 要修正の比率）でランク判定（S〜D）を表示

### なぜ雑か

テキスト量の上限は〜3000字（それ以上は要約してから貼ってほしいのだ）。質問の質は Claude 任せで同じ小説を2回実行すると似た質問が来ることがある。ジャンル特性（ファンタジーの魔法体系など）を考慮した質問には弱い。ゲームオーバー / クリア判定はスコアの閾値を決め打ちするだけ。

### 雑な技術スタック候補

Next.js + Claude Haiku API + localStorage（セッション管理） + Vercel 無料枠

## 1. 在庫番犬

- カテゴリ: ガジェット
- 対象ユーザー: 一人暮らし・忙しい家庭でトイレットペーパーやコーヒー豆を切らして困る人
- 一行で: 棚に置くだけの重量センサーが残量を検知して減ったらLINEで教えてくれるのだ

### 解決する痛み

気づいたらトイレットペーパーが最後の1個、コーヒー豆が切れて朝から絶望、という経験は誰にでもある。Amazon定期便は消費ペースが変わると余ったり足りなかったりで信用できず、結局都度買いに行くのを忘れる。冷蔵庫の中身管理アプリのように手入力する気力もない。実際の残量を見てから発注判断したいのに、それを見る手段がない。

### 1 週間で作るならこれ

- ロードセル（重量センサー）+ HX711 + ESP32 で棚板の重さを常時計測
- 初回に「満タン重量」を1回だけ登録するキャリブレーション画面
- 残量が閾値（例: 20%）を下回ったらWi-Fi経由でLINE Notify APIに通知
- 1台のセンサーにつき1品目のみ対応（棚板ごとに1台設置）
- ダッシュボードなし、通知のみで過去の消費グラフは見られない

### なぜ雑か

複数商品を1枚のセンサーで区別しない（重さの合算値しか見ない）。振動や地震で誤検知しても無視する。センサーの経年ドリフト補正なし。電源はUSB給電のみでバッテリー駆動は非対応。棚への固定方法は木の板とテープで済ませ、筐体設計はしない。

### 雑な技術スタック候補

ESP32 + HX711 + ロードセル(1kg) + Arduino IDE + LINE Notify API + 木材とグルーガンで即席筐体

## 2. サブスク棚卸し

- カテゴリ: Web
- 対象ユーザー: 契約したサブスクを把握しきれず無駄な支払いを続けている個人
- 一行で: クレカ明細CSVを貼るだけで繰り返し課金を自動検出して一覧化するのだ

### 解決する痛み

気づけば使っていないサブスクに毎月課金され続けている。銀行やクレカの明細を毎月1件ずつ目視で確認するのは面倒すぎて誰もやらない。マネーフォワードのような口座連携型の家計簿は導入が大掛かりで抵抗がある人も多い。CSVをアップロードするだけで「これ、まだ要る?」を突きつけてほしい。

### 1 週間で作るならこれ

- 主要クレカ3社のCSVフォーマットに対応した明細アップロード画面
- 同じ加盟店名 + ほぼ同額の取引が月次で3回以上出現するものを「サブスク候補」として抽出
- 検出したサブスク一覧を月額順に表示、年間換算額も併記
- 各項目に「使ってる / 解約済み / わからない」の3ボタンでステータスを手動記録
- 「わからない」に分類された合計額を目立つ色でハイライト表示

### なぜ雑か

対応CSVフォーマットは主要3社限定、それ以外は非対応。加盟店名の表記ゆれ（Amazon.co.jp と Amazon Payments など）は正規化せず別々に検出されることがある。解約手続きへの導線は作らない（気づかせるだけ）。外貨建て明細は非対応。データはブラウザのlocalStorageのみに保存しサーバーには送らない。

### 雑な技術スタック候補

Next.js（フロントのみ、APIサーバー不要）+ PapaParse（CSV解析）+ localStorage + Recharts（簡易グラフ）

## 3. Merge Conflict Dojo

- カテゴリ: ゲーム
- 対象ユーザー: マージコンフリクトに毎回焦る新人〜中堅エンジニア
- 一行で: 本物っぽい衝突diffをその場で手動解決する反射神経ゲームなのだ

### 解決する痛み

実際のマージコンフリクトに出くわすと「<<<<<<< HEAD」を見ただけで固まってしまう人は多い。解決方法は知識として知っていても実践量が足りず、本番のPRで焦って `git checkout --theirs` を連打して意図しない上書き事故を起こしがち。そもそも練習する場がない。

### 1 週間で作るならこれ

- ありがちな衝突パターン（同じ関数の別修正・import順序衝突・フォーマット崩れ）を10問プリセットで用意
- ブラウザ上でコンフリクトマーカー付きコードを表示し、解決後のコードをテキストエリアに入力させる
- 送信すると期待コードと空白無視で文字列比較し正誤判定、経過秒数も記録
- 10問終わったら合計スコアと平均解決時間だけを表示
- 難易度は初級のみ（3ファイル以上の複雑な衝突は出題しない）

### なぜ雑か

実際のgit環境とは連携せず静止テキストの穴埋め問題として出題する。正誤判定は文字列比較に近く「意味的に正しいが書き方が違う」解答は誤答扱いになる。問題は10問固定でランダム生成しない。マルチプレイやランキング機能は作らない。

### 雑な技術スタック候補

Vite + React + 静的JSON問題データ + diff2html（表示用）+ localStorage（スコア保存）

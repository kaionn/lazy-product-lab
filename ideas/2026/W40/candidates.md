## 1. CI時間泥棒ランキング

- カテゴリ: CLI
- 対象ユーザー: GitHub Actionsの実行時間・課金に頭を悩ませているチームの開発者
- 一行で: ワークフロー名を渡すだけでどのジョブ・ステップが時間とお金を溶かしているかランキングしてくれるのだ

### 解決する痛み

月末にGitHub Actionsの請求額を見て「なんでこんなに高いんだ」と青ざめるが、どのワークフローのどのステップが原因か調べるのが面倒でActions画面を何十回もクリックする羽目になる。同じような重いテストジョブが並列で何度も走っていたり、キャッシュが効かず毎回フルインストールしているステップに誰も気づかないまま放置される。「一覧で犯人を教えてくれ」というだけの話。

### 1 週間で作るならこれ

- GitHub API（`workflow runs` / `jobs` エンドポイント）から直近30日分の実行ログのメタデータを取得
- ジョブ名・ステップ名ごとに実行時間を集計し、ランナーの秒単価から概算コストを計算
- 「合計時間」「平均時間」「実行回数」でソートしたランキングをターミナルにテーブル表示
- 上位5件は「このステップ、キャッシュ効いてなさそう」の簡易ヒント（ステップ名にinstall/buildを含むかで判定）を添える
- `--repo owner/name` 一発で完結、設定ファイル不要

### なぜ雑か

自己ホストランナーの料金体系には対応せずGitHub公式従量課金の単価固定値で概算するだけ。ステップ内部の詳細プロファイリングはしない（ログのタイムスタンプ差分のみ）。マトリクスビルドは1本ずつ別カウントで畳み込まない。過去30日を超えるログはページネーションを追わず切り捨てる。

### 雑な技術スタック候補

Node.js + Commander + GitHub REST API (Octokit) + cli-table3

## 2. フォーカス泥棒キャッチャー

- カテゴリ: デスクトップアプリ
- 対象ユーザー: 集中して作業したいのに通知やポップアップでウィンドウフォーカスを奪われ続ける開発者
- 一行で: 集中モードを起動するだけで作業中にフォーカスを奪ったアプリを後から犯人ランキングで見せてくれるのだ

### 解決する痛み

「集中するぞ」とコーディングを始めても、Slackの通知やアップデートダイアログにいつの間にかフォーカスを奪われてタイプミスしたり誤操作したりする。終わった頃には「今日は何にどれだけ邪魔されたか」を体感でしか把握できず、通知設定を見直す判断材料もない。

### 1 週間で作るならこれ

- タスクトレイに常駐し「集中スタート」ボタンで計測開始
- OSのアクティブウィンドウ変化イベントを監視し、集中対象アプリ以外にフォーカスが移った瞬間を記録
- セッション終了時に「奪ったアプリ名 × 回数 × 合計奪取時間」のランキングをポップアップ表示
- 集中対象アプリ（エディタ・ターミナルなど）は事前に1回だけ選択して保存
- 直近7セッション分の履歴を簡易グラフで振り返れる

### なぜ雑か

マルチモニターでの細かいフォーカス判定は雑（1回のウィンドウ切り替えイベント単位でしか見ない）。通知の内容までは読まない（アプリ名だけ）。Windows対応の手間は避けMac版のみ先に作る。集中中に自分の意思でブラウザを見た場合も「奪われた」扱いになる誤検知は許容する。

### 雑な技術スタック候補

Electron + macOS Accessibility API (NSWorkspace通知) + Chart.js

## 3. 経費レシート二重申請ハンター

- カテゴリ: 業務ツール (Web)
- 対象ユーザー: 月末に大量の経費精算をチェックする経理担当者
- 一行で: 経費申請のCSVを貼るだけで金額・日付・店名が近い二重申請の疑いを一覧にしてくれるのだ

### 解決する痛み

経費精算システムから出力したCSVを目視で1件ずつ確認しているが、同じ飲み会の領収書を2人が別々に申請していたり、同じ人が同じ店の同じ金額を月をまたいで2回申請していたりするケースを見逃しがちで、月末になるほどチェックが雑になる。Excelで並べ替えてもタイポや店名の表記ゆれで気づけない。

### 1 週間で作るならこれ

- 経費CSV（申請者・日付・店名・金額）をアップロードするだけのフォーム
- 金額完全一致 かつ 日付±3日以内 の組み合わせを総当たりで検出
- 店名は簡易的な文字列類似度（レーベンシュタイン距離）でゆれを吸収してマッチング
- 疑わしい組み合わせを「申請者A・申請者B／金額／日付差」のテーブルで表示、CSVで書き出し
- 誤検知を手動で「問題なし」チェックして次回から除外できるリスト機能

### なぜ雑か

OCRでの領収書画像自体の照合はせずCSVのテキスト情報のみで判定する。3件以上の多重申請は2件ずつのペア表示に分解して力技で見せる。海外通貨や税抜税込みの差異は考慮しない。過去データとの突き合わせは同一CSV内のみで、月をまたいだ蓄積比較は今回はスコープ外。

### 雑な技術スタック候補

Next.js + PapaParse (CSVパース) + fast-levenshtein + Vercel

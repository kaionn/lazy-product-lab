## 1. フレーキー犯人捜し

- カテゴリ: CLI
- 対象ユーザー: CIがたまにコケて「また再実行ボタン押した」が口癖になっているエンジニア
- 一行で: テストコマンドを連続実行するだけで怪しいテストをランキングしてくれるのだ

### 解決する痛み

CI が赤くなるたびに「これ本当に自分のせい?」と疑いながら再実行ボタンを押し、緑になったら「まあいいか」で流してしまう。実は特定のテストが週に何度もコケているのに、原因を探ろうにも失敗ログはCIの奥深くに埋まっていて手動集計する気力がない。気づけば「またあれか」がチームの共通認識になっているのに、誰も直す時間を取らない。

### 1 週間で作るならこれ

- pytest/jest 等のテストコマンドを指定してN回連続実行するCLIコマンド
- 各テストの成功/失敗を実行ごとに記録してSQLiteに蓄積
- 失敗率が閾値(例: 5%以上)を超えたテストを「フレーキー候補」としてランキング表示
- ランキングをターミナルにテーブル表示(テスト名・失敗回数・失敗率)
- 結果をMarkdownレポートとして書き出すオプション

### なぜ雑か

失敗原因の切り分け(タイムアウトなのかアサーション不一致なのか)はしない。並列実行時のリソース競合は考慮せず直列実行のみ対応。過去のCI履歴は取り込まず、手元で回した分しか集計しない。テストフレームワークはpytestとjestのみ、他は非対応のまま。閾値はハードコード。

### 雑な技術スタック候補

Python + Click + subprocess + SQLite + rich (テーブル表示)

## 2. 尻ブザー

- カテゴリ: ガジェット
- 対象ユーザー: 在宅勤務で気づいたら3時間座りっぱなしになっているエンジニア
- 一行で: 椅子の下に敷くだけで座りすぎたらブザーで教えてくれるのだ

### 解決する痛み

集中してコードを書いていると気づけば3時間座りっぱなしで、立ち上がると腰が悲鳴を上げている。スタンディングデスクは高いし、PC通知のリマインダーアプリは無視する癖がついてしまった。椅子に何か置くだけで「今どれくらい座っているか」を体感で気づかせてほしい。画面の隅ではなく、体で気づきたい。

### 1 週間で作るならこれ

- 椅子の座面下に敷く薄型の圧力センサー(FSR)+ ESP32
- 圧力を検知したらタイマー開始、離席で圧力が消えたらリセット
- 座り続けて60分を超えたら圧電ブザーを鳴らして立たせる
- 立ち上がってから5分以上経過したらタイマーを完全リセット
- LEDで現在の連続着席時間を色でざっくり表示(緑→黄→赤)

### なぜ雑か

座り方や姿勢の良し悪しは判定せず、圧力の有無だけで着席を判定する。複数人が交代で座る環境では誤作動する前提。ブザーの音量調整はハードコードで固定。Wi-Fi接続や着席時間の記録機能はなく、その場で鳴って終わり。ケースは作らず配線むき出しのままで完成とする。

### 雑な技術スタック候補

ESP32 + FSR圧力センサー + 圧電ブザー + Arduino IDE + フルカラーLED

## 3. 見た目差分番人

- カテゴリ: Web (SaaS)
- 対象ユーザー: フロントエンドのPRでCSS崩れを見逃してマージしてしまった経験があるエンジニア
- 一行で: 2つのURLを貼るだけで画面のピクセル差分をハイライトして見せてくれるのだ

### 解決する痛み

フロントエンドのPRをレビューするとき、コードだけ読んで「多分大丈夫だろう」とマージしてしまい、後から「このボタンだけ変な位置にずれてる」と気づく。プレビュー環境を毎回自分の目でスクロールして確認するのは面倒だし、細かい1pxのズレは肉眼では気づきにくい。PercyやChromaticは高機能だがセットアップが重く、個人開発や小さなPRには使う気になれない。

### 1 週間で作るならこれ

- 比較したい2つのURL(本番/プレビュー)を入力するだけのフォーム
- Playwrightで両方のページのフルページスクリーンショットを取得
- pixelmatchで差分を計算し、変化した領域を赤枠でハイライトした画像を生成
- 差分ピクセル数が閾値を超えたページだけ「要注意」バッジを表示
- 結果ページのURLを発行してSlackやPRコメントに貼れるようにする

### なぜ雑か

ログインが必要なページやモーダル操作が絡む画面は対象外。レスポンシブ対応は1つの画面幅(1280px)のみでモバイル表示は見ない。アニメーションやフォントレンダリングの揺らぎによる誤検知は許容する。差分画像を見せるだけでDOM構造の差分説明はしない。認証やチーム機能はなく、URLを知っていれば誰でも結果を見られる。

### 雑な技術スタック候補

Next.js + Playwright + pixelmatch + Vercel Blob (画像保存) + Vercel

## 1. standup-gen

- カテゴリ: CLI
- 対象ユーザー: 毎朝スタンドアップに何を話すか迷う開発者
- 一行で: git log を喰わせたら昨日分スタンドアップ原稿が出る

### 解決する痛み

「昨日何してたっけ？」と朝イチに git log を漁る時間が地味に辛い。コミットメッセージは技術的すぎて非技術者向けに読み替えるのも面倒。結果「えーと、色々やってました」で終わる。

### 1 週間で作るならこれ

- `standup-gen` コマンドが直近 24h の `git log --oneline` を自動収集
- Claude API に投げて「何をやった・何が残っている・ブロッカー」3点形式に整形
- `--lang ja/en` フラグで出力言語切り替え
- `--copy` フラグでクリップボードに直接コピー
- `.standuprc` で「このリポジトリは無視」などの除外設定

### なぜ雑か

複数リポジトリの横断や PR タイトルの取得は実装しない。git log が取れる範囲のみ。エラーハンドリングは「失敗したら素直に落ちる」で十分。

### 雑な技術スタック候補

Python + Claude API (claude-haiku-4-5) + pyperclip + argparse、pip でインストールできる形

## 2. kakaku-hover

- カテゴリ: Browser Extension
- 対象ユーザー: Amazon JP / 楽天で買い物するセール待ち勢
- 一行で: 価格にホバーしたら過去 90 日の最安値がポップアップ

### 解決する痛み

「今の価格って安いの？」を判断するために別タブで価格比較サイトを開く手間が常にある。セール中の煽り文句「過去最安値！」は嘘も多く、自分で履歴を確認する術がない。

### 1 週間で作るならこれ

- Amazon JP の商品ページで ASIN を抽出し Keepa API (無料枠) に投げる
- 楽天ページでは商品 ID を抽出し 楽天商品価格 API に問い合わせ
- ホバー時に Canvas で簡易折れ線グラフ (90 日) をポップアップ表示
- 「過去最安値」と「現在価格の乖離 %」を数字で表示
- Chrome のみ対応、Firefox は後回し

### なぜ雑か

Keepa 無料枠は月 100 リクエスト制限があり超えたらグラフが出ないだけ。楽天以外の ECサイトは未対応。グラフは Canvas でゴリ押し、ライブラリ不使用。

### 雑な技術スタック候補

Chrome Extension (Manifest V3) + Keepa Public API + 楽天市場 API + Vanilla JS + Canvas 2D

## 3. multi-timer-wall

- カテゴリ: モバイル (PWA)
- 対象ユーザー: 複数品目を同時に調理する自炊勢
- 一行で: 料理の複数タイマーをキッチンから見える大画面で管理

### 解決する痛み

「パスタ 8 分・ソース 15 分・ガーリックブレッド 5 分」を同時に回すとき、スマホの標準タイマーは 1 件ずつしか名前がつけられず、鍋の前に立ったまま確認しにくい。時計アプリを複数立ち上げる方法はカオス。

### 1 週間で作るならこれ

- タイマーを「名前 + 分数」で追加してカード表示、複数同時進行
- 残り時間が大きなフォントで表示、カウントダウン中は背景色がじわじわ変化
- 終了時に Web Speech API で「パスタが終わりました」と音声読み上げ
- スマホブラウザのホーム画面追加 (PWA) に対応し全画面で使える
- localStorage で「よく使うセット」を保存・呼び出し

### なぜ雑か

通知は画面が表示されている間のみ有効。バックグラウンド通知は Service Worker + Notification API が必要で実装しない。タイマーの一時停止も初版は非対応。

### 雑な技術スタック候補

Next.js (App Router) + Tailwind + Web Speech API + localStorage、Vercel に 1 コマンドデプロイ

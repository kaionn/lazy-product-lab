## 1. slack-poker

- カテゴリ: Bot
- 対象ユーザー: リモートスクラムチームのスクラムマスター・チームリード
- 一行で: `/poker タスク名` 一発でプランニングポーカーが Slack に起動

### 解決する痛み

リモートチームでプランニングポーカーをやるとき、Miro や専用ツールを開いて URL を共有して…の手順が面倒で省略されがち。結果、見積もりがリードの一存で決まる。Slack コマンド一発で匿名投票→結果公開まで完結すれば、ツール切り替えの摩擦がなくなる。

### 1 週間で作るならこれ

- `/poker タスク名` コマンドでセッション開始、Slack Blocks で「1, 2, 3, 5, 8, 13, ?, ☕」ボタン表示
- 各メンバーが自分の画面でボタンをクリック→票は非公開で蓄積
- ファシリテーターが「公開」ボタンを押すと全員の票と平均が一括 reveal
- `/poker-cancel` でセッションをキャンセル
- 同チャンネルで同時に複数セッションは未対応（1 チャンネル 1 セッション）

### なぜ雑か

タイムアウト処理なし。投票済みかの重複チェックは Vercel KV の有効期限任せで揮発あり。複数ワークスペースへの配布（OAuth フロー）は実装しない。自チームの1ワークスペースに手動インストールのみ。

### 雑な技術スタック候補

Bolt for JS (Slack SDK) + Vercel Serverless Functions + Vercel KV (Redis)

## 2. 1bit-dungeon

- カテゴリ: ゲーム
- 対象ユーザー: 休憩 5 分だけ遊びたいレトロゲーム好きの会社員・学生
- 一行で: 広告ゼロ・キーボードだけの ASCII ローグライクがブラウザで即起動

### 解決する痛み

ブラウザゲームは広告や課金誘導が多く、5 分だけ遊びたいのに余計なものが多すぎる。インストール不要でキーボードだけで完結するシンプルなゲームが意外と見つからない。URL を開けば即遊べる ASCII ローグライクが欲しい。

### 1 週間で作るならこれ

- 15×15 マスの ASCII ダンジョンをランダム生成（`@`プレイヤー、`#`壁、`.`床、`E`モンスター、`$`ゴールド）
- 矢印キーで移動、モンスターに隣接したターンに自動攻撃（HP 計算のみ）
- モンスター AI はランダム移動のみ、10 階到達で CLEAR 表示
- ゴールドを集めて最終スコアを localStorage に保存してランキング表示
- 全体を Single HTML ファイルで完結、CDN なし・ライブラリなし

### なぜ雑か

アイテム・魔法・ボスは実装しない。ゲームバランスは適当。デザインはモノスペースフォント＋黒背景だけ。「死んだら即終了」でセーブなし。

### 雑な技術スタック候補

Vanilla HTML / JS / CSS（single-file、フレームワーク・ライブラリ完全不使用）

## 3. tui-drill

- カテゴリ: 学習ツール
- 対象ユーザー: ターミナルで仕事中に隙間勉強したいエンジニア・資格受験者
- 一行で: YAML に書いた単語帳をターミナルで間隔反復学習

### 解決する痛み

Anki は高機能だが「起動→デッキ選択→クリック」の手順が重い。ターミナルで作業中にコマンド一発で 3 問だけ出したい。単語帳もコードと同じテキスト (YAML) で管理してバージョン管理したい。

### 1 週間で作るならこれ

- `drill.yaml` に `q: / a: / tags:` 形式で問題を書く（Markdown 記法 OK）
- `tui-drill run` で TUI 起動、問題表示→スペースで答え reveal→j(正解)/f(不正解) でスコア記録
- SM-2 アルゴリズム（簡略版）で次回出題日を計算し `~/.drilldb.json` に保存
- `tui-drill add "問題" "答え"` でコマンドラインから即追記
- `tui-drill stats` でデッキ別の正答率と今日期日の問題数を一覧表示

### なぜ雑か

画像・音声カードは未対応。YAML バリデーションは雑でエラー出力が素っ気ない。複数デバイス間の同期なし。SM-2 パラメータ調整 UI なし。

### 雑な技術スタック候補

Python 3 + Textual (TUI ライブラリ) + PyYAML + JSON、pipx でグローバルインストール

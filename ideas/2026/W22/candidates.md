## 1. git-standup-gen

- カテゴリ: CLI
- 対象ユーザー: 複数リポジトリを掛け持ちするフリーランス開発者・副業エンジニア
- 一行で: git log から昨日の作業を自動スタンダップ文に変換

### 解決する痛み
「昨日何やったっけ？」がリモートワークのスタンダップで頻発する。複数リポジトリ間で作業していると git log を手でたどって整理するのが地味に面倒で、毎朝 5〜10 分無駄になる。コミットメッセージを人間語に変換してくれるツールが欲しい。

### 1 週間で作るならこれ
- 指定ディレクトリ以下の git リポジトリを自動検出
- 24 時間以内の自分のコミットを取得しフォーマット整形
- 「やったこと / やること / ブロッカー」の 3 項目テンプレート出力
- `--copy` フラグでクリップボードにコピー
- `~/.standup.toml` で対象リポジトリと著者メール設定

### なぜ雑か
コミットメッセージが雑なプロジェクトでは出力も雑になる。自然言語変換なし、「fix bugs」がそのまま出てくる。Slack/Teams への直接投稿機能は含まない。

### 雑な技術スタック候補
Python 3 + subprocess (git log) + pyperclip + tomllib / Go 単一バイナリでも可

## 2. MeetingCost.live

- カテゴリ: Web
- 対象ユーザー: 会議が多いと感じている中間管理職・チームリード
- 一行で: 今この会議にいくらかかってるか可視化するタイマー

### 解決する痛み
「この会議、本当に必要？」という感覚はあるのに、コストが見えないから惰性で続く。参加者数と平均時給を入れるだけでリアルタイムの金額カウンターを表示し、共有 URL を会議前に Slack に貼れる。

### 1 週間で作るならこれ
- 参加人数 + 平均時給（円 / ドル切替）を入力するフォーム
- リアルタイムカウンター（円表示、1 秒更新）
- URL に状態を埋め込んで共有可能（クエリパラメータ）
- スタート / ポーズ / リセットボタン
- 会議終了時の合計コスト表示とコピーボタン

### なぜ雑か
アカウント不要・DB なし・ログなし。URL 共有のみで永続化なし。デザインは Tailwind のデフォルトで十分。モバイル最適化は後回し。

### 雑な技術スタック候補
Next.js (静的エクスポート) + Tailwind + Vercel 無料枠、状態は URL クエリパラメータのみ

## 3. envdoc

- カテゴリ: CLI
- 対象ユーザー: OSS リポジトリのメンテナー・新規参入者が多いプロジェクトの開発者
- 一行で: コードを静的解析して .env.example を自動生成

### 解決する痛み
新しいリポジトリをクローンすると `.env` の設定方法が README に書いていないことが多い。コードを全部読んで `process.env.XXX` を探すのは時間の無駄。`envdoc` を走らせれば使われている環境変数を一覧化し、型ヒントとデフォルト値つきの `.env.example` を自動生成できる。

### 1 週間で作るならこれ
- JS/TS (`process.env.FOO`) · Python (`os.environ['FOO']`, `os.getenv`) · Go (`os.Getenv`) の静的解析
- 既存の `.env.example` と差分を取り「未記載の変数」を警告
- 変数名から型推測（`PORT` → number, `ENABLED` → boolean, etc.）
- コメントつき `.env.example` を自動生成または上書き
- CI で「未記載変数があったら fail」するための exit code 対応

### なぜ雑か
動的に組み立てた変数名（`process.env['PREFIX_' + name]`）は検出できない。正規表現ベースで AST 解析なし。多言語の混在プロジェクトは個別対応が必要。

### 雑な技術スタック候補
Go 単一バイナリ (regexp + bufio) または Python + re + argparse、GitHub Actions サンプル同梱

## 1. CodeGolfBattle

- カテゴリ: ゲーム
- 対象ユーザー: アルゴリズム問題が好きなエンジニア・競プロ勢
- 一行で: 最短コードで出力を一致させる非同期バトル場

### 解決する痛み

AtCoder や LeetCode は「速さ」しか競えない。コードの短さ（バイト数）を競う気軽な場所がほぼない。「このコード 30 バイトで書けるか？」という遊びを友達と非同期でやりたいのに、そのための場所がない。コードゴルフ専門サイトは敷居が高く、カジュアルに遊べない。

### 1 週間で作るならこれ

- 問題ページ: 「入力 X を受け取って出力 Y を返せ」という仕様を表示
- コード提出フォーム → Judge0 API でサンドボックス実行 → 出力が一致したらバイト数をスコア登録
- リーダーボード: 問題ごとに最短コードランキングを表示（言語別フィルタ付き）
- 問題は 10 問ハードコード（Python / JS / Ruby で解きやすいもの）
- 「提出コードを見る」ボタンで他人のコードを解禁（自分が解いた問題のみ）

### なぜ雑か

任意コード実行は Judge0 API の無料枠任せでセキュリティ保証なし。Rate limit に引っかかったら黙って「実行失敗」にする。問題の追加は手動でソースを直接編集。コードの盗用防止ゼロ。

### 雑な技術スタック候補

Next.js + Vercel + Vercel KV (スコア保存) + Judge0 API (コード実行) ─ バックエンドレスで全部 API Routes に収める

## 2. FeedDigest

- カテゴリ: SaaS
- 対象ユーザー: RSS を登録したまま未読が溜まりすぎて諦めたリサーチャー・ライター
- 一行で: RSS を登録したら毎朝 Notion に要約が届く

### 解決する痛み

RSS リーダーに 500 件の未読が溜まって開くのが怖くなる。「全部読まなきゃ」のプレッシャーで結局 Slack や Twitter に情報源が戻ってしまう。大事そうな記事とノイズを見分けるために全部開くのが時間の無駄。毎朝 3 行の要約が Notion に届くだけで、情報収集のコスパが激変するはずなのだ。

### 1 週間で作るならこれ

- セットアップ: RSS URL を登録 + Notion Integration Token を貼るだけ
- 毎朝 7 時に各フィードの新着記事を取得 → Claude API で 3 行要約を生成
- Notion Database に「タイトル / 要約 / 元 URL / フィード名 / 取得日時」を自動追加
- フィードごとに「重要度キーワード」を設定して高スコア記事を先頭に並び替え
- Web UI はフィード管理ページのみ（Notion が読書 UI になる）

### なぜ雑か

RSS フィードが壊れていたら黙って次の実行まで放置。要約精度は Claude 任せで保証なし。Notion の Relation や Formula との連携は考慮しない。有料プランなし・無料で使い放題のまま（将来課金設計ゼロ）。

### 雑な技術スタック候補

Python + feedparser + Anthropic SDK (claude-haiku-4-5) + Notion API + Railway (Cron ジョブ) ─ 月コスト $0〜$5 で収まる想定

## 3. MoistAlert

- カテゴリ: ハードウェア
- 対象ユーザー: 観葉植物を枯らしがちなインドア植物初心者
- 一行で: 土が乾いたら LED が光って水やりを教えてくれる装置

### 解決する痛み

「土が乾いたら水をやる」と分かっていても、仕事や外出で忘れる。毎日決まった時間に水をやると過水で根腐れする。指を刺して確認するのが毎回面倒。スマートホーム系の高価なデバイスは 1 鉢 6,000 円〜で複数鉢置けない。安い容量式土壌センサーと ESP32 を組み合わせれば 500 円以下で作れるのに、ちょうどいい完成品 OSS がない。

### 1 週間で作るならこれ

- 容量式土壌センサー + ESP32 + LED 1 個を組み合わせたシンプル回路
- 土壌水分が閾値以下になったら LED が点滅し始める
- ESP32 が Wi-Fi 経由でローカル Flask サーバーに 5 分おきにデータを送信
- ブラウザで今日の水分レベル折れ線グラフを確認できる（LAN 内のみ）
- 「水やりした」ボタンを押すとログに記録 → 週の水やり回数が分かる

### なぜ雑か

センサー精度は土の種類・肥料・温度に依存するためキャリブレーションは「雰囲気で閾値を調整してください」スタンス。複数鉢対応なし。防水なし（水やり時に濡らさないこと）。電源は USB 固定でバッテリー駆動未対応。

### 雑な技術スタック候補

ESP32 + MicroPython + 容量式土壌センサー (STEMMA QT 互換) + Python Flask + Chart.js ─ 部品代 500 円、ホスティングなし

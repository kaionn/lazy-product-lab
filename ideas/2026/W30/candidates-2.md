## 1. AmbiPixel

- カテゴリ: ガジェット
- 対象ユーザー: ゲーマー・映画好きの自作 PC ユーザー
- 一行で: ゲーム画面に合わせてモニター裏LEDが自動で色を変える

### 解決する痛み

Philips の Ambilight TV は現実的な価格ではない。PC 向けの Ambilight クローンソフト (Hyperion, Prismatik 等) は設定が複雑で、Arduino/Adalight の配線を調べるだけで半日かかる。「とにかく動くもの」を求めているが「全手順を書いたページ」が存在しない。結果、YouTube でビデオを見ながら作ろうとして挫折するか、$200 のキットを買う二択になる。

### 1 週間で作るならこれ

- Python スクリプトでモニター端 (上/左/右/下) の平均色をフレームごとにサンプリング
- USB シリアル経由で Raspberry Pi Pico W に色データを送信 (115200 bps)
- Pico W 上の MicroPython が WS2812B LED ストリップ (54 灯) を制御
- 全 LED をセグメント分割してモニター端の対応ゾーンに色を割り当て
- 起動スクリプト 1 本で全プロセス立ち上げ、Config は JSON で変更可能

### なぜ雑か

フレームレートは目標 20fps だが実測 8-12fps になりがち。HDMI キャプチャ非対応 (スクリーンキャプチャ API のみ)。多モニター非対応。LED 数・レイアウトは 54 灯ハードコード。Pico W の Wi-Fi 機能は未使用。映像ゲームより動きの少ない作業画面向き。

### 雑な技術スタック候補

Python 3 + mss + pyserial + Raspberry Pi Pico W + MicroPython + WS2812B LED ストリップ (部品合計 ¥1,500 前後)

## 2. WaariMae

- カテゴリ: モバイル (PWA)
- 対象ユーザー: 友人グループでの外食・旅行時に割り勘計算をしたい人
- 一行で: 注文バラバラな会計を秒で割り勘、アプリ不要

### 解決する痛み

5 人で居酒屋に行くと注文がバラバラで会計が混乱する。Splitwise はアカウント登録が必要。紙の計算は遅い。スマホの電卓アプリで一人ずつ足し算するのも手間。「この鍋は A と B が頼んだ、このドリンクは C 一人」を正確に追跡できるツールが存在しない。簡単・無登録・スマホで完結が理想なのだ。

### 1 週間で作るならこれ

- アイテム名・金額・注文した人 (複数選択可) を入力する画面
- 自動で「誰が誰にいくら払う」の最小取引数ルートを計算して表示
- URL のハッシュにデータをシリアライズして QR コードで他人と共有
- 消費税・サービス料の % 割増しオプション
- 支払い完了チェックボックスで未清算の人を強調表示

### なぜ雑か

サーバーレス・DB なし (URL ハッシュ状態のみ)。入力項目が多いと URL が長くなり QR が読みづらくなる (ユーザー責任)。最小取引アルゴリズムは未最適化で大人数だと遅くなる可能性あり。履歴保存なし。オフライン対応なし。

### 雑な技術スタック候補

Vite + Preact + Tailwind CSS → GitHub Pages 静的ホスト (バックエンドなし)

## 3. IssueVote

- カテゴリ: SaaS
- 対象ユーザー: OSS プロジェクトのメンテナー
- 一行で: GitHub IssueにCanny不要で「欲しい」票を集めるウィジェット

### 解決する痛み

OSS メンテナーは「どの Issue を先に直すべきか」を Comment 数と +1 絵文字で判断するしかない。Canny / UserVoice はエンタープライズ向けで無料枠が小さく OSS には向かない。GitHub の thumbs-up リアクションはスパムされやすくノイズが多い。メンテナーが「ユーザーが本当に望むもの」を数値で把握する手段がなく、人気機能が何年も放置される。

### 1 週間で作るならこれ

- GitHub OAuth でメンテナーがリポジトリを登録
- オープン Issues 一覧を投票ウィジェットとして表示する公開 URL を発行
- GitHub アカウントなしでメール認証のみで 1 Issue 1 票の投票が可能
- 投票数でソートされた Issues 一覧をメンテナーダッシュボードで確認
- README にコピペできる「Vote on Issues」バッジ + リンク HTML スニペット生成

### なぜ雑か

スパム対策はメール認証のみ (同一メールで 1 票、使い捨てメール対策なし)。Issues のリアルタイム同期なし (手動リフレッシュ)。Labels / Milestones などの GitHub 情報は未取得。投票データのエクスポート機能なし。1 リポジトリのみ対応 (複数リポジトリ管理は未実装)。

### 雑な技術スタック候補

Next.js 15 + NextAuth (GitHub OAuth) + Prisma + PostgreSQL (Supabase 無料枠) + Vercel 無料枠

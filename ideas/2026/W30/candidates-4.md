## 1. タスクスイッチくん

- カテゴリ: ハードウェア
- 対象ユーザー: フリーランス・副業エンジニアでタイムトラッキングが続かない人
- 一行で: 物理ボタンを押すだけで今やってる作業をTogglに記録

### 解決する痛み

「後で時間を振り返ろう」と思っても Toggl を起動する気になれず、月末の請求書を書くとき「あの作業何時間やったっけ？」が全然分からない。PC の画面を開くたびにタイムトラッカーアプリを切り替える手間が積み重なって結局やめる。物理ボタンが目の前にあれば切り替えコストがゼロになる。ターミナルを閉じなくていい。

### 1 週間で作るならこれ

- ESP32 + 4 個のタクタイルスイッチ + 4 個の LED をブレッドボードで配線
- ボタン 1〜4 に「コーディング / ミーティング / レビュー / 休憩」を割り当て
- ボタン押下時に Toggl REST API を叩いて前タスクを終了・新タスクを開始
- 押したボタンの LED が点灯して現在タスクを常時表示
- `http://taskswitch.local/` で各ボタンのラベルと Toggl プロジェクト ID を設定

### なぜ雑か

ラベルは 4 種類固定でボタン 4 個以上は未対応。ネット断絶時のオフラインバッファなし（タスク消失）。Toggl 以外の時間管理サービスには対応しない。ケースなしブレッドボード剥き出しのままで完成とする。API トークンは `config.h` に直書き。

### 雑な技術スタック候補

Arduino IDE + ESP32 + arduino-esp32 + HTTPClient (Toggl v9 API) + ArduinoJson + mDNS + LittleFS (設定保存)

## 2. PageWatch

- カテゴリ: SaaS
- 対象ユーザー: 競合他社の料金ページや採用ページを定期チェックしているスタートアップ社員・フリーランサー
- 一行で: 競合URLを登録したら変化した瞬間にメールが来るのだ

### 解決する痛み

「競合の料金ページが変わったら教えてほしい」を手動で月 1 回確認している。ブックマークして時々開くが、そもそも前回と何が変わったのか一目でわからない。変化検知ツールを自前で Puppeteer + cron で構築する気力もない。Distill.io は設定が煩雑でプラン管理が面倒。「URL を貼ったら後は任せる」が欲しい。

### 1 週間で作るならこれ

- URL を登録するだけの Web フォーム（メールアドレス + URL + チェック頻度：1日/3日/1週）
- Headless Chrome (Playwright) で対象 URL の HTML テキストを定期取得
- 前回取得との diff を計算、変更行が 3 行以上なら変化ありと判定
- 変化を検知したらメールで「どの URL が変化した・何行変わった」を通知（Resend）
- 登録 URL は 1 アカウント最大 5 件まで（無料枠の乱用防止）

### なぜ雑か

JavaScript レンダリング後のコンテンツ差分は見るが画像変化は検知しない（HTML テキストのみ）。変化した箇所のハイライト表示なし（メールには「N 行変化した」とだけ書く）。ログインページ / CAPTCHA があるサイトには無力。1 サイトあたりのクロール実行時間が 10 秒を超えるとタイムアウトで諦める。

### 雑な技術スタック候補

Next.js + Supabase (DB + cron jobs via pg_cron) + Playwright + Resend + Vercel 無料枠でホスト

## 3. あるきメモ

- カテゴリ: モバイル
- 対象ユーザー: 散歩・通勤中にアイデアが浮かぶが立ち止まってメモできないエンジニア・ライター
- 一行で: 歩きながら喋ったら帰ったらテキストになってるのだ

### 解決する痛み

シャワーや散歩中に良いアイデアが浮かんでも、スマホを出して文字を打つのが億劫で消えていく。音声メモアプリはあるが「後で聴き直す気になれない」し「テキストに起こしてくれない」。Google Keep の音声入力はリアルタイム文字起こしで失敗すると消える。録音したままの音声ファイルが溜まって結局聴かない問題。

### 1 週間で作るならこれ

- 大きな「録音」ボタン 1 個の画面で即録音スタート（アプリ起動 → 録音まで 2 タップ以内）
- 録音終了後に Whisper API に送って自動文字起こし（30 秒以内に完了するスコープ）
- 文字起こし結果をカード形式でタイムライン表示（日付・録音時間・先頭 2 行プレビュー）
- カードをタップで全文表示・コピー・削除のみ（編集機能は作らない）
- 全メモを 1 つの Markdown ファイルとしてエクスポートするボタン

### なぜ雑か

オフライン文字起こしなし（Whisper API 必須、通信圏外では録音のみ保存される）。話者分離なし。長い録音（3 分超え）はそのまま送るので Whisper の課金が青天井になりうる。音声ファイルはアプリのローカルストレージのみ（クラウド同期なし）。Android 対応は MVP スコープ外（iOS Expo のみ）。

### 雑な技術スタック候補

React Native (Expo) + expo-av (録音) + OpenAI Whisper API + expo-file-system (ローカル保存) + Expo Go で即確認

## 1. 資料未読あぶり出しくん

- カテゴリ: Bot (Slack)
- 対象ユーザー: 事前資料を共有しても誰も読まずに会議に来る文化のチームのオーガナイザー
- 一行で: 会議前に共有した資料の閲覧履歴を見るだけで未読者だけにこっそりリマインドしてくれるのだ

### 解決する痛み

会議前にGoogle DocsやNotionの資料URLを共有しても、開かれずに会議当日を迎え、「これ資料に書いてあるんですけど…」の説明で毎回10分溶ける。オーガナイザーが個別に「読みました？」と聞くのも気まずいし、全員に一律リマインドすると読んだ人にまで催促が飛んで嫌がられる。閲覧履歴を見れば誰が読んでいないかは一瞬でわかるのに、誰もそのために毎回APIを叩きに行かない。

### 1 週間で作るならこれ

- Slackコマンドで会議とGoogle Docs/Notionの資料URLを登録
- Google Docs Activity API / Notion APIで閲覧者一覧を会議開始30分前に取得
- 閲覧履歴に載っていない参加者だけへ個別にSlack DMで「資料まだ読んでないですよ」を送信
- 会議開始5分前にオーガナイダーへ未読者リストをまとめて通知
- 1会議につき資料は1件のみ対応（複数資料の管理は次回）

### なぜ雑か

「開いた」を「読んだ」とみなし、スクロールして最後まで見たかは判定しない。Google Docs・Notion以外のツールは非対応。参加者リストはGoogleカレンダーの招待をそのまま使い、当日追加された人は無視する。DM送信は1回だけで既読になった後の取り消し通知もない。

### 雑な技術スタック候補

Slack Bolt (Node.js) + Google Docs Activity API + Notion API + Google Calendar API + Vercel Cron

## 2. 握りつぶし例外ハンター

- カテゴリ: CLI
- 対象ユーザー: 本番障害の原因調査で「あ、ここで例外を握りつぶしてた」を毎回発見するバックエンドエンジニア
- 一行で: リポジトリを渡すだけで何もしないcatchブロックをランキングで教えてくれるのだ

### 解決する痛み

try/catchでエラーを捕まえたのに中身が空、あるいはconsole.logだけで処理を継続する「握りつぶしcatch」がコードベースに散らばっていて、レビューでは素通りしがちなのに障害調査になると必ずそこが原因になる。grepで探そうにも書き方がバラバラで見つけきれず、結局本番ログを何時間も追ってから気づく羽目になる。

### 1 週間で作るならこれ

- リポジトリパスを渡すとAST解析（Babel）でtry-catchブロックを全走査
- catch内が空・console.logのみ・コメントのみのものを「握りつぶし」として抽出
- ファイルパス・行番号・catch内のコードを危険度付き（ログなし＝高、ログのみ＝中）でランキング表示
- 対象はJS/TypeScriptのみ
- `--ignore` オプションで意図的な握りつぶしパターンを除外リストに登録

### なぜ雑か

JS/TS以外の言語には対応しない。async/awaitのtry-catchは検出するがPromise.catch()チェーンは対象外。「握りつぶし」の判定は固定ルールのヒューリスティックで、リトライ処理などの正当な空catchも無差別に検出してしまう。

### 雑な技術スタック候補

Node.js CLI + @babel/parser + @babel/traverse + chalk + npm packageとして配布

## 3. 自転車いじられ番

- カテゴリ: ガジェット
- 対象ユーザー: 駅の駐輪場に自転車を停めていて盗難・いたずらが不安な通勤・通学者
- 一行で: サドル下に貼るだけで自転車が動かされた瞬間LINEで教えてくれるのだ

### 解決する痛み

駅前の駐輪場に自転車を停めている間、誰かに倒されたり荷台を開けられたりしていないか気になるが、確認のために様子を見に行くわけにもいかない。本格的なGPS盗難防止デバイスは月額料金がかかって大げさだし、そもそも位置追跡までは求めていない。「動かされたら教えてほしい」だけなのに、そのためだけの安いデバイスがない。

### 1 週間で作るならこれ

- ESP32 + 振動センサー(SW-420)をサドル下に防水ケースで固定
- 振動が閾値を超えたら即座にLINE Notify APIで「自転車が動かされました」と通知
- 風などの微振動を無視するため、連続検知回数がしきい値を超えた時だけ発報
- モバイルバッテリー駆動、1週間持てば良しとする
- 専用アプリは作らずLINEグループ通知のみで完結させる

### なぜ雑か

GPS追跡機能はなく、盗まれた後の位置は分からない「触られた」通知のみ。誤検知対策は最低限で強風の日は誤報が増える前提。防水はジップロック程度の簡易対応。バッテリー残量チェックはなく、切れたら手動で気づいて交換する。

### 雑な技術スタック候補

ESP32 + SW-420振動センサー + LINE Notify API + 3.7Vリポバッテリー + 防水ジップ袋

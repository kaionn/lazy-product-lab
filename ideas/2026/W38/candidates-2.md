## 1. 経費按分くん

- カテゴリ: 業務ツール (Web)
- 対象ユーザー: 在宅勤務の個人事業主・フリーランスで確定申告の経費按分に悩む人
- 一行で: 光熱費と作業時間を入力するだけで在宅経費の按分計算書が自動でできるのだ

### 解決する痛み

確定申告の時期になるたびに「電気代のうちどれだけ経費にできるんだっけ」を毎年ゼロから調べ直す。国税庁の床面積按分や使用時間按分の考え方を検索し、Excelで一から計算式を組み、12ヶ月分の光熱費明細をかき集める作業が地味にしんどい。去年の按分率をどう出したかも忘れていて毎回同じ苦労を繰り返している。

### 1 週間で作るならこれ

- 部屋の床面積（全体・仕事スペース）と週の作業時間を入力するフォーム
- 電気・ガス・水道・通信費の月額を12ヶ月分手入力
- 床面積按分/時間按分のどちらかを選んで按分率を自動計算
- 月ごとの経費計上額を一覧表示し、年間合計をCSV・PDFで出力
- 按分率の根拠（考え方の簡単な注記）を出力書類に添付

### なぜ雑か

電力会社の明細PDFを自動で読み取る機能はなく手入力のみ。法人成り後の複数事業には対応しない。按分方法は2種類だけで複雑な変動按分は非対応。税理士によるレビューは含まず、あくまで下書き作成止まり。過去年度分の一括インポートも作らない。

### 雑な技術スタック候補

Next.js + Supabase (認証+DB) + react-hook-form + jsPDF (PDF出力) + Vercel 無料枠

## 2. ミーティング量産犯人捜し

- カテゴリ: Bot (Slack)
- 対象ユーザー: 社内の会議が増えすぎて疲弊しているチームのマネージャー・スクラムマスター
- 一行で: Googleカレンダーを繋ぐだけで誰が一番会議を量産してるか週次ランキングで晒してくれるのだ

### 解決する痛み

「最近会議が多い」とみんな感じているのに、誰がどれだけ会議を主催しているかが可視化されていないので指摘しづらい。1on1で「もう少し減らして」と伝えても本人には自覚がなく翌週も同じペースで会議が増える。カレンダーを人力で集計してグラフにする気力もなく、結局誰も手をつけない。

### 1 週間で作るならこれ

- Google Calendar APIでチームメンバーの主催イベントを週次取得
- 主催会議数と延べ会議時間（参加者数×時間）を集計
- 毎週月曜朝にSlackへ「先週の会議量産ランキングTOP3」を投稿
- 30分未満・参加者5人以下の小さい会議は除外するフィルタ設定
- ランキング投稿へのリアクションで匿名の「もっと減らして」票を集計表示

### なぜ雑か

Google Calendar以外（Outlook等）には対応しない。個人予定か会議かの判定は「参加者2人以上」という簡易ルールのみ。時系列のトレンドグラフはなく直近週との比較のみ。ランキングを晒すだけで改善アドバイスや自動調整は行わない。

### 雑な技術スタック候補

Google Calendar API + Slack Bolt (Node.js) + Vercel Cron + Supabase (集計データ保存)

## 3. 冷凍庫サルベージくん

- カテゴリ: モバイル (PWA)
- 対象ユーザー: まとめ買い・作り置き派の一人暮らし・共働き家庭
- 一行で: 冷凍庫にしまう時に撮るだけで賞味期限が近づくと救出リマインドが来るのだ

### 解決する痛み

冷凍庫の奥で何ヶ月も忘れられた食材や作り置きが、扉を開けるたびに「これいつ入れたんだっけ」となり、結局賞味期限切れで捨てる罪悪感が積み重なる。ラベルを手書きして貼るのも面倒で三日坊主になり、紙やメモアプリで在庫管理しようとしても更新が止まってしまう。

### 1 週間で作るならこれ

- 冷凍する時に写真を撮り品名と冷凍日を入力（過去入力から候補表示）
- 食品カテゴリごとの推奨消費期限をデフォルトで自動セット（肉1ヶ月・ご飯1ヶ月・スープ2週間など）
- 期限が近づいたらPWA Push通知で「そろそろ○○を食べて」と知らせる
- サムネイル付きカード一覧で表示し、消費したらスワイプで削除
- 期限切れのまま放置された件数を「冷凍庫の罪悪感スコア」として表示

### なぜ雑か

バーコードスキャンや画像認識による品名自動判定はなく手入力が必須。家族間の共有機能はなく1人1台の利用を前提とする。消費期限は編集できるが栄養成分などの詳細情報は扱わない。オフライン時の通知はブラウザPushの仕様に依存し、環境によっては届かないことがある。

### 雑な技術スタック候補

React (Vite) + PWA (Workbox) + IndexedDB (ローカル保存) + Web Push API + Cloudflare Pages

## 1. ShelfSnap

- カテゴリ: モバイル
- 対象ユーザー: 積読が山積みの読書家・本棚を整理したい人
- 一行で: 背表紙をカメラで撮るだけで読書記録が完成

### 解決する痛み
「この本もう持ってたっけ？」で同じ本を2冊買う。Notion や読書メーターに手入力するのが面倒で続かない。「どこまで読んだか」メモがバラバラで引っ越しのたびに積読が再発見される。贈り物に本を選んだら相手が既に持っていた。

### 1 週間で作るならこれ
- カメラで背表紙のバーコードを撮影して ISBN を取得
- Google Books API で書誌情報（タイトル・著者・表紙画像）を自動補完
- 「未読 / 読書中 / 読了」の 3 ステータス管理
- ローカル SQLite に保存、CSV エクスポートボタン
- タイトル・著者での全文検索

### なぜ雑か
OCR が読めない本は手入力。Kindle ライブラリとの同期なし。シリーズ順の管理なし。複数ユーザー非対応。カバーデザインが似た本の誤認識は無視。

### 雑な技術スタック候補
React Native (Expo) + expo-camera + Google Books API + expo-sqlite

## 2. CommitHeat

- カテゴリ: 業務ツール
- 対象ユーザー: 自分の生産性パターンを知りたいリモートエンジニア・フリーランサー
- 一行で: git log から「本当の黄金時間帯」を炙り出すCLI

### 解決する痛み
「自分は朝型だ」と思っているが数値的な根拠がない。タスク管理ツールのレポートは「タスクを触った時間」であってコードを書いた時間ではない。フリーランスの請求時間を見積もる参考に、実際にコミットした時間帯のパターンが欲しい。カレンダーを埋めるほどでもない軽いセルフ分析がしたい。

### 1 週間で作るならこれ
- ローカルの git リポジトリを複数指定して `git log` を一括取得
- コミット時刻を「時間帯 × 曜日」のヒートマップで SVG 出力
- ピーク時間帯トップ 3 を自動算出してターミナルに表示
- 月別推移グラフ（先月 vs 今月の比較）
- `--html` フラグで HTML レポート一枚を生成してブラウザで開く

### なぜ雑か
コミット時刻はローカルタイムゾーン依存なのでリモート作業とズレる。コミット数 ≠ 生産性だが無条件に同一視。マージコミットを除外しない。作業内容の質は一切考慮しない。

### 雑な技術スタック候補
Python + Click + GitPython + matplotlib + Jinja2

## 3. PomoLight

- カテゴリ: ガジェット
- 対象ユーザー: 在宅勤務中に家族・同居人に集中を切られるエンジニア
- 一行で: Pico W で光る交通信号、集中中を部屋に宣言する

### 解決する痛み
在宅勤務中に「ちょっといい？」と声をかけられてフロー状態が消し飛ぶ。「集中中」の付箋は誰も見ない。Slack ステータスは同じ部屋の人には届かない。バーチャル背景では作業中かどうか伝わらない。子どもには文字より光の方が直感的に分かる。

### 1 週間で作るならこれ
- Raspberry Pi Pico W + RGB LED 3 個（赤・黄・緑）をブレッドボードで配線
- 25 分集中（赤点灯）→ 移行（黄点滅）→ 5 分休憩（緑点灯）の自動ポモドーロサイクル
- ブラウザから `http://pico.local/` でスタート / リセット / 強制休憩を操作
- Web UI でカスタム時間（例: 50 分 / 10 分）を設定できる
- 本体の物理ボタン 1 個で即休憩モードに切り替え

### なぜ雑か
Wi-Fi 環境必須で LAN なしでは動かない。電源は USB のみでバッテリーなし。ケースなくブレッドボード剥き出し。Slack / Google Calendar との自動連携なし。LEDs が 3 個しかないので細かい状態（何周目か）は表示不可。

### 雑な技術スタック候補
MicroPython + Pico W + asyncio + utemplate (HTML/JS ワンファイル埋め込み)

## 1. lazydiff-commit

- カテゴリ: CLI
- 対象ユーザー: ソロ開発者・個人プロジェクト多い人
- 一行で: diff 読んでコミット文を自動生成、LLM 不要

### 解決する痛み

`git diff` を見ながら conventional commit を書くのが面倒で「fix stuff」「update」みたいな無意味コミットが量産される。LLM に投げるには大げさ、でも毎回手で考えるのも億劫。変更ファイルのパスと追加/削除行のキーワードを見れば 80% くらいは機械的に推定できるはずなのだ。

### 1 週間で作るならこれ

- `git diff --staged` を解析して変更ファイル一覧・行数を取得
- `feat/fix/chore/docs/refactor/test` をパスと差分内容の heuristic で推定
- スコープをトップレベルディレクトリから自動推定
- コミット候補を 3 つ生成して fzf でインタラクティブ選択
- 選択したメッセージで `git commit -m` を実行

### なぜ雑か

LLM なしのキーワードマッチなので正確性は保証しない。リネーム・バイナリファイル・日本語ファイル名は未対応。候補が外れていたら手打ちしてください、のスタンス。

### 雑な技術スタック候補

Go + cobra + os/exec + 簡単な heuristic ロジック + fzf (外部バイナリ依存)

## 2. potluck-score

- カテゴリ: Web
- 対象ユーザー: 宅飲み・持ち寄りパーティーを定期的にやるグループ
- 一行で: 持ち寄りの貢献度をゆるく可視化するスコアボード

### 解決する痛み

「あいつはいつも手ぶらで来る」問題。LINE で請求するほどじゃないし、割り勘アプリは重い。でも貢献度が見えれば自然にみんな持ってくるようになる。URL を送るだけで参加でき、ゆるくスコアが溜まっていくサイトが欲しい。

### 1 週間で作るならこれ

- ルーム作成 → URL をシェアするだけで参加可能 (認証なし)
- 参加者を名前で登録
- イベントごとに「誰が何を持ってきたか」を記録
- 貢献度スコアを自動集計してリーダーボード表示
- 過去イベント履歴の閲覧

### なぜ雑か

認証なし・誰でも編集可能・スコア計算ロジックは品目数カウントのみで金額は無視。セキュリティ皆無なので内輪専用。

### 雑な技術スタック候補

Next.js + Vercel + Vercel KV (Redis) ─ インフラ費用ほぼゼロで済む

## 3. vocab-drip

- カテゴリ: Bot
- 対象ユーザー: 英語学習中で Slack / Discord を日常的に使うエンジニア
- 一行で: 毎朝 Slack に 1 単語ポスト、開くだけで語彙が増える

### 解決する痛み

英単語アプリは「起動する」コストで挫折する。毎朝 Slack/Discord は絶対開く。その流れで 1 単語に触れる仕組みがあれば継続できる。単語帳アプリを別で開く必要がなくなる。

### 1 週間で作るならこれ

- TOEIC 800+ 相当の単語リスト (約 1000 語) を JSON で内蔵
- 毎朝指定時刻に 1 単語 + 品詞 + 意味 + 例文 2 文を投稿
- リアクション 📌 で自分の「要復習リスト」に追加 (DM に蓄積)
- `/vocab-quiz` コマンドで今週投稿された単語を 4 択クイズ出題
- `/vocab-stats` で自分の 📌 数と正答率を表示

### なぜ雑か

単語選択は日付シードのランダム順なので、学習効率の最適化は一切なし。個人ごとの進捗管理・SRS (間隔反復) は実装しない。単語リストのライセンスは自作 JSON で乗り切る想定。

### 雑な技術スタック候補

Python + discord.py (または slack-bolt) + JSON データファイル + Railway 無料枠でホスト

## 1. Clipboard Spy

- カテゴリ: Browser Extension
- 対象ユーザー: Stack Overflow やブログからコードをコピーして開発するエンジニア
- 一行で: コピーしたコードの出典 URL を自動保存して後から追跡

### 解決する痛み
Stack Overflow・GitHub Gist・技術ブログからコードをコピーして使うとき、後から「このコードどこから持ってきたっけ？」と出典を忘れる。ライセンス確認したいとき、バグ修正版が出たとき、チームメンバーに説明するとき——クリップボード履歴アプリは入れているが URL との紐付けがない。

### 1 週間で作るならこれ
- ブラウザ上でコピーしたテキストをインターセプト（30 文字以上を対象）
- コピー元の URL・ページタイトル・タイムスタンプを localStrage に保存
- 拡張のポップアップで「最近コピーした履歴」一覧を表示（最大 50 件）
- ドメインでフィルタ（`github.com` だけ見たい、など）
- 1 クリックで元ページを新タブで開く

### なぜ雑か
コピー内容は先頭 100 文字だけ保存。iframe 内コピーは取れない。履歴は localStorage だけなのでブラウザをクリアすると消える。シークレットモード非対応。

### 雑な技術スタック候補
Chrome Extension Manifest V3 + Vanilla JS + localStorage

## 2. Deploy Dash

- カテゴリ: ゲーム
- 対象ユーザー: インシデント対応の経験が少ない若手バックエンドエンジニア
- 一行で: 本番障害をテキストで模擬体験する焦りシミュレーター

### 解決する痛み
本番インシデントは滅多に起きないから経験値が積めない。でも初めてオンコールになったとき「何から見ればいいか分からず 10 分ロスした」が起きがち。Runbook を読んでも実際のプレッシャー下で動けるか不安。ハンズオン研修を社内で組むコストも高い。

### 1 週間で作るならこれ
- テキストベースのシナリオ 6 本（DB 接続過多・OOM・DNS 障害・デプロイ起因の 500・外部 API 障害・キュー詰まり）
- 各シナリオでコマンドを選択 → 結果テキストが返る（正解パスと罠パスあり）
- 制限時間 5 分、TTD / TTFR / TTR の 3 指標でスコア表示
- クリア後に正解パスを追う解説モードあり
- ブラウザで完結する SPA（インストール不要）

### なぜ雑か
シナリオは 6 本固定でランダム要素なし。入力はプルダウン選択式（自由テキスト入力は実装コスト高）。マルチプレイヤーなし。実際のクラウド環境との連携なし。

### 雑な技術スタック候補
Next.js（静的エクスポート）+ TypeScript + Zustand + Vercel

## 3. Changelog Radar

- カテゴリ: Web
- 対象ユーザー: 依存ライブラリを定期アップデートするフロント / バックエンドエンジニア
- 一行で: package.json を貼るだけで破壊的変更をまとめて確認

### 解決する痛み
`npm outdated` で古いパッケージを一覧できても、どれをアップデートしたら壊れるか分からない。CHANGELOG を全部読む時間はない。Dependabot の PR が溜まって見て見ぬふりをしてしまう。アップデートしたら突然テストが全落ちして「またか…」となる。

### 1 週間で作るならこれ
- package.json をテキストエリアにペースト
- npm registry API で各パッケージの最新版と現行版を取得
- GitHub の CHANGELOG.md / releases を取得して LLM で差分を日本語要約
- 「安全」「要確認」「危険（破壊的変更あり）」の 3 段階でラベル付け
- アップデート推奨順にソートして一覧表示

### なぜ雑か
CHANGELOG がない or フォーマットが変なパッケージは「確認できませんでした」で終わり。monorepo の workspaces 非対応。yarn.lock / pnpm-lock.yaml は無視。LLM 要約のハルシネーションは保証しない。

### 雑な技術スタック候補
Next.js + Claude Haiku API + npm registry API + Vercel

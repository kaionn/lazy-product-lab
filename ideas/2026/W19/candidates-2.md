## 1. スクショ奉行

- カテゴリ: Browser Extension
- 対象ユーザー: 調査・資料作成が多いビジネスパーソン・デザイナー
- 一行で: スクショ保存と同時にページタイトル+日付で自動リネーム

### 解決する痛み
`Screenshot_20260510_123456.png` が100枚溜まって「あのスクショどこだっけ」問題。手動リネームは絶対忘れる。フォルダ整理は週1でやろうと思って半年放置。でも専用アプリを入れるほどでもない、という温度感。

### 1 週間で作るならこれ
- ダウンロード発生時にページタイトル + ドメイン + 日付を組み合わせたファイル名に自動リネーム
- 禁則文字（ / : * ? " < > | ）の自動除去と長さ上限（100字）トリミング
- 保存先サブフォルダのカスタム指定（例: `Screenshots/仕事` / `Screenshots/個人`）
- ドメイン別ルール設定（例: GitHub → `gh-` プレフィックス付き）
- ポップアップで直近5件のリネーム履歴を確認・手動修正

### なぜ雑か
ブラウザ外スクショ（OS標準のPrintScreen）は対象外。動画サイトのタイトル取得は壊れやすくてノーサポート宣言。同名ファイルの連番処理はブラウザ任せ。

### 雑な技術スタック候補
Vanilla JS + Chrome Extension Manifest V3 (downloads API + storage API)、Chrome Web Store に公開

## 2. ランチガチャ

- カテゴリ: Web
- 対象ユーザー: 毎日ランチ場所で迷うオフィスワーカー・在宅勤務者
- 一行で: ガチャを回すだけで今日のランチが決まるのだ

### 解決する痛み
「今日ランチどこ行く?」という無限ループ。複数人で決める時の「どこでもいい」「なんでもいい」チキンレース。Googleマップで近くの店を探すが選択肢が多すぎて逆に疲れる。

### 1 週間で作るならこれ
- 現在地（Geolocation API）からOpenStreetMap Overpass APIで半径500m以内の飲食店取得
- ガチャ演出（スロット風アニメーション3秒）でランダムに1件抽出
- ジャンルフィルタ（和食 / 洋食 / 中華 / カフェ / なんでも）
- 「ハズレ」ボタンで即再ガチャ（直前の結果は除外）
- 結果をURLパラメータ付きでシェア（チームのSlackに貼って共有）

### なぜ雑か
営業時間・定休日チェックなし（開いてるかどうかは自分で確認してほしいのだ）。口コミ評価は一切見ない。半径は500m固定で変更不可（MVP版は）。地方では店数が少なくてガチャ失敗する可能性あり。

### 雑な技術スタック候補
Next.js + Tailwind + Vercel（無料枠）、OpenStreetMap Overpass API（無料・無認証）

## 3. ドキュメント耳読みくん

- カテゴリ: 学習ツール
- 対象ユーザー: 通勤中に技術ドキュメントを消化したいエンジニア
- 一行で: 技術ドキュメントのURLを貼るだけで耳で聴けるのだ

### 解決する痛み
通勤時間を使って技術ドキュメントを読みたいが、コードブロックが含まれると音声化が崩壊する。Podcastはあるが読みたいドキュメントはPodcastになっていない。Read Aloud系拡張は「`const foo = bar.map(x => x.id)`」を全部読み上げて意味不明。

### 1 週間で作るならこれ
- URLを貼るとHTMLからメインコンテンツを抽出（Readability.js使用）
- コードブロックを「コード例、省略」に置換してからTTS化
- ブラウザのWeb Speech API で再生（追加課金ゼロ）
- 再生速度調整スライダー（0.75x / 1x / 1.25x / 1.5x / 2x）
- 段落ごとにハイライト表示（再生位置を視覚的に追える）

### なぜ雑か
数式・図表・表組みは全無視。日本語・英語以外の言語は音声品質保証なし。TTSの音質はブラウザ依存で端末によって別物になる。オフライン動作不可。ページがJavaScript依存だとコンテンツ取得に失敗することあり。

### 雑な技術スタック候補
Python + FastAPI + BeautifulSoup4 + Readability-lxml、フロントはVanilla JS + Web Speech API、Render 無料枠でホスト

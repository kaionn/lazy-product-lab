## 1. env-doctor

- カテゴリ: CLI
- 対象ユーザー: チームで開発するバックエンド/フルスタック開発者
- 一行で: .envの差分と型ミスを瞬時に検出するのだ

### 解決する痛み
`.env.example` を更新し忘れてチームメンバーが本番/開発環境でキー欠損エラーを踏む問題が頻発する。さらに「数値のはずが空文字」「URL形式が壊れている」といった型の不整合は、実行してみるまで気づけない。CIに組み込める検査ツールがほしいが、大掛かりなスキーマ定義は書きたくない。

### 1 週間で作るならこれ
- `.env` と `.env.example` の差分チェック（欠損キー・余剰キー一覧）
- コメントによる型ヒント(`#type:int` / `#type:url` / `#type:bool`)を読んで型チェック
- シークレット候補キー（`SECRET` / `TOKEN` / `KEY` を含む）の値が短すぎる場合に警告
- CI 向け exit code 設定（問題あり=1、なし=0）
- `--fix` フラグで `.env.example` のキー一覧を自動同期

### なぜ雑か
型チェックはコメント書式を決め打ちで、その書式が書かれていないキーは完全スルー。型定義のスキーマファイルも不要。エッジケース（マルチライン値、引用符のネスト）は無視。

### 雑な技術スタック候補
Node.js + commander.js（外部依存ゼロ目標）、npm publish で配布

## 2. PomodoroBattle

- カテゴリ: Bot
- 対象ユーザー: Discord を使うリモートワーカー・受験生・個人開発者
- 一行で: 仲間と集中時間を競うポモドーロBotなのだ

### 解決する痛み
一人でポモドーロを回しても続かない。Discord のボイスチャンネルで友人と一緒に作業したいが、全員がバラバラのタイマーを使っていて「いまどのフェーズ？」が共有されない。かといって専用アプリを入れるハードルは高い。

### 1 週間で作るならこれ
- `/pomo start` でそのチャンネルの全員にタイマー開始通知（25分集中→5分休憩）
- 参加者ごとの完了セッション数をその日のランキング形式でテキストチャンネルに投稿
- セッション完了時に Discord の絵文字リアクションで自動お祝い（🍅）
- `/pomo stats` で自分の週間合計集中時間を確認
- `/pomo skip` で現在フェーズを強制スキップ

### なぜ雑か
タイムゾーン対応なし（サーバーオーナーがUTCオフセットを手動設定）、複数サーバー間のランキング統合なし、1サーバー1チャンネル同時進行のみ。再起動するとタイマー状態がリセットされる。

### 雑な技術スタック候補
discord.py + SQLite、Render 無料枠でホスト、cron で日次ランキングリセット

## 3. タイポ探偵

- カテゴリ: ゲーム
- 対象ユーザー: OSS 貢献に興味があるプログラミング初心者・英語学習者
- 一行で: 実コードのタイポを見つけてOSSデビューするのだ

### 解決する痛み
「OSS に貢献したいけど何から始めればいい？」のハードルが高い。typo 修正は最も簡単なコントリビュートだが、対象リポジトリをどこから探せばいいか分からない。ゲーム形式で探す体験があれば、OSS 貢献を自然に始められる。

### 1 週間で作るならこれ
- GitHub API でスター数上位リポジトリのコメント・変数名・ドキュメントを取得してよくあるタイポ候補をリストアップ
- 1 問ずつ「これタイポ？」と提示し、ユーザーが正しいスペルを入力するクイズ形式
- 正解するとポイント獲得、対象ファイルへの GitHub PR 作成リンクも表示
- 1 日 5 問制限でカジュアルプレイ、スコアは localStorage 保存
- 週次ランキング（スコア上位 10 人を静的 JSON で表示）

### なぜ雑か
タイポ検出は固定辞書（よくある英語タイポ 200 語）との単純マッチング。GitHub API レート制限は考慮せず、詰まったら「明日また来てね」表示で逃げる。

### 雑な技術スタック候補
Vanilla JS + GitHub REST API、GitHub Pages で静的ホスト（バックエンドなし）

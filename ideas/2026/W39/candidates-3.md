## 1. 誕生日ドラフトくん

- カテゴリ: Bot (LINE)
- 対象ユーザー: 友人・親戚の誕生日にいつも当日になって慌ててメッセージを送っている人
- 一行で: 友人の誕生日を登録するだけで数日前にAIが書いたお祝いメッセージ案がLINEで届くのだ

### 解決する痛み

友人の誕生日をカレンダーに登録していても、当日の朝にリマインドが来てから「今日中に何か送らなきゃ」と焦り、結局「おめでとう！」の一言だけで終わってしまう。関係性やその人の近況を踏まえた一言を添えたいと思っても、忙しい日にその余裕はない。前もって考えておけば済むのに、いつも当日になってから思い出す。数日前に下書きが届いていれば、そこから少し編集して送るだけで済む。

### 1 週間で作るならこれ

- LINE Bot に友人の名前・誕生日・関係性（親友/同僚/親戚など）・直近のメモ（近況一言）を登録
- 誕生日の3日前に対象者の情報を元にAIがお祝いメッセージ案を3パターン生成してLINEで送信
- 「このまま使う/編集する」ボタンでコピー用テキストとして表示するだけ（送信自体は本人が別途LINEで行う）
- 登録は1グループにつき最大30人まで
- 誕生日を過ぎたら「送った?」を自動で聞いて既読管理

### なぜ雑か

実際の送信は代行しない（コピペしてもらうだけ）。近況メモは自分で手入力必須で他サービスとの連携なし。誕生日以外の記念日（結婚記念日など）には対応しない。メッセージのトーンは「フレンドリー」固定で敬語モードはなし。同じ日に誕生日が重なる人が複数いても個別に生成するだけで一括処理はしない。

### 雑な技術スタック候補

LINE Messaging API + Node.js (Cloudflare Workers) + Supabase + OpenAI API (メッセージ生成) + cron (誕生日3日前チェック)

## 2. 駐車場迷子救済くん

- カテゴリ: モバイル (PWA)
- 対象ユーザー: 大型商業施設・空港・遊園地の広い駐車場で車の場所を忘れる人
- 一行で: 駐車した時に1タップで場所を記録するだけで戻ってきた時に道順を教えてくれるのだ

### 解決する痛み

ショッピングモールや空港の立体駐車場で「何階の何番だったか」を忘れて延々と歩き回った経験は誰にもある。フロア番号の看板を写真に撮っても後で見返さないし、メモ帳アプリに入力するのも面倒で結局やらない。買い物袋を両手に抱えた状態で車を探すのは地味にストレスが大きい。駐車した瞬間にワンタップで済むなら習慣化できる。

### 1 週間で作るならこれ

- PWA起動画面に大きな「ここに停めた」ボタン1つ
- タップした瞬間のGPS座標・時刻・任意で看板の写真1枚を保存
- 「車を探す」ボタンでGoogleマップの経路案内を保存座標宛に自動起動
- 保存した場所は直近5件だけ履歴として一覧表示（古いものは自動削除）
- オフラインでもGPS座標の保存は可能（写真アップロードのみ通信が必要）

### なぜ雑か

屋内駐車場でGPSが弱い場合の精度補正はしない（フロア番号はメモ欄への手入力でカバーする運用）。複数人でのシェア機能なし。車種や色などの情報管理もなし。iOS Safariのホーム画面追加PWA限定でネイティブアプリ化はしない。

### 雑な技術スタック候補

Vite + React (PWA) + Geolocation API + IndexedDB (履歴保存) + Google Maps URL Scheme (経路起動)

## 3. よくある質問掘り出し人

- カテゴリ: SaaS
- 対象ユーザー: 少人数チームでサポート業務（メール・チャット）を兼務している担当者
- 一行で: 過去のサポートメールを貼るだけで繰り返し来る質問をまとめてFAQ案を作ってくれるのだ

### 解決する痛み

小さいチームのサポート担当は同じような質問に何度も個別で答えていて、FAQページを作る余裕がないまま同じ返信をコピペし続けている。「あの質問、前にも来たな」と思いながらも一つひとつのメールに個別対応するのが精神的に疲れる。FAQを作ろうと思っても「どの質問が本当に多いのか」を数える作業自体が面倒で着手できない。過去のメールをまとめて放り込むだけで頻出パターンが見えれば着手のハードルが下がる。

### 1 週間で作るならこれ

- 過去のサポートメール本文をまとめてテキストボックスに貼り付け（コピペ・CSV両対応、最大200件）
- AIが質問内容を意味的にクラスタリングして頻出トピック上位10件を件数付きで表示
- 各トピックについてAIが回答テンプレート案を1つ生成
- クラスタごとに元メールへのリンク（何番目の投稿か）を表示して裏取りできるようにする
- 生成されたFAQ一覧をMarkdownで一括エクスポート

### なぜ雑か

リアルタイム連携（メールボックスの自動取り込み）はせず貼り付け専用。クラスタリング精度は雑（意味が近いだけで別の質問がまとまることもある）。多言語混在には対応しない（日本語想定のみ）。生成した回答テンプレートは事実確認せず出すだけなので、公開前に人間のレビュー必須という前提。

### 雑な技術スタック候補

Next.js + OpenAI API (embedding + クラスタリング + 生成) + Vercel + ローカルstate管理のみ（DB不要、貼り付け都度処理）

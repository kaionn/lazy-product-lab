## 1. コメントアウト墓場発掘人

- カテゴリ: CLI
- 対象ユーザー: 大きめのレガシーリポジトリを触るエンジニア
- 一行で: リポジトリを渡すだけで放置されたコメントアウトコードの塊を経過日数付きでランキングしてくれるのだ

### 解決する痛み

プロダクトコードの中に「念のため残しておいた」コメントアウトのコードブロックが何年も放置され、誰も消す勇気を持てない。grep しても大量にヒットして本当に消していいものが分からず、1つずつ git blame で確認するのは面倒すぎて結局誰もやらない。レビューでも「まあいいか」で通り過ぎ、ファイルはどんどん読みにくくなっていく。一番古くて一番デカいブロックから機械的に晒せれば、掃除の優先順位が一瞬で分かる。

### 1 週間で作るならこれ

- 対象拡張子を指定してリポジトリ内の全ファイルを走査
- 行頭が `//` `#` `/* ... */` などコメント記号で始まる行が3行以上連続するブロックを検出
- 各ブロックの最終更新日を `git blame` で取得し放置日数を計算
- 放置日数×行数でスコアリングしてランキング表示（ファイル名・行番号・先頭1行プレビュー付き）
- `--top 20` で上位N件だけ表示するオプション

### なぜ雑か

コメント内が実際にコード片かどうかの厳密な構文解析はせず、記号の並びだけで判定するため誤検知あり（説明文の長いコメントも拾ってしまう）。対応するコメント記法は主要どころ（`//` `#` `/* */`）のみ。自動生成ファイルの除外は `.gitignore` 参照のみで個別設定はしない。削除の自動実行はせず一覧を出すだけで終わる。

### 雑な技術スタック候補

Python + GitPython + argparse、正規表現でコメントブロック抽出、rich ライブラリで標準出力にテーブル整形

## 2. エアコン消し忘れ番

- カテゴリ: ガジェット
- 対象ユーザー: 在宅勤務中や外出前にエアコンを消し忘れがちな一人暮らし
- 一行で: コンセントに挟むだけで誰もいないのにエアコンが動いていたらLINEで教えてくれるのだ

### 解決する痛み

出かける前に「あれ、エアコン消したっけ」と不安になって家に戻って確認したり、逆に消し忘れたまま一日中運転させて電気代が跳ね上がったりする。人感センサー単体だと在室判定が甘く、テレビの光や観葉植物の揺れにも反応してしまう。エアコン自体をスマート家電に買い替えるのはハードルが高いし、既存のコンセントに挟むだけで後付けできる安さと手軽さが欲しい。

### 1 週間で作るならこれ

- 電力計測付きスマートプラグでエアコンの消費電力を1分おきに取得
- 同じ部屋に置いた人感センサーで在室・不在を判定
- 「不在なのに消費電力が閾値以上」の状態が15分続いたらWebhook経由でLINEに通知
- スマホアプリは作らずWeb管理画面で閾値（W数）と通知先だけ設定
- 誤検知対策として「今日は許可」ボタンを1つだけ用意し30分だけ通知を止められる

### なぜ雑か

複数部屋やマルチエアコン環境は非対応（1部屋1プラグ限定）。留守判定は人感センサー1個のみなので、外出中に家族の誰かが在室しているケースは誤爆する。電力閾値は機種ごとに手動設定が必要で自動学習はしない。停電やWi-Fi切断時の再接続処理は作り込まない。

### 雑な技術スタック候補

SwitchBot/TP-Link Kasa プラグAPI + ESP32 + PIRセンサー + LINE Notify互換Webhook + Raspberry Pi Zeroでポーリングスクリプト常駐

## 3. 出演シーンだけ会議リプレイ

- カテゴリ: Web (AI ツール)
- 対象ユーザー: 大量の録画会議を見返す時間がないPM・エンジニア
- 一行で: 会議の録画を渡すだけで自分が映って喋ってる場面だけ繋ぎ合わせたダイジェスト動画を作ってくれるのだ

### 解決する痛み

参加できなかった会議や、途中から気が逸れていた会議の録画を「1時間丸ごと見返す」気力がなく結局放置してしまう。文字起こし要約はあっても、自分の発言や名前が呼ばれた場面の空気感（トーンや相手の反応）までは伝わらない。動画編集ソフトで該当シーンを自分で切り出すのは時間がかかりすぎて誰もやらない。自分の名前が出た瞬間だけ繋げたショート動画が自動で出てくれば、3分で「自分ごと」の部分だけ把握できる。

### 1 週間で作るならこれ

- 会議録画ファイル（mp4）と自分の名前・呼ばれるニックネームをアップロード
- Whisperで文字起こしし、タイムスタンプ付きテキストを取得
- 発言者名または名前の言及があるタイムスタンプの前後10秒を候補区間として抽出
- ffmpegで候補区間だけを結合したダイジェスト動画（最大5分）を書き出し
- ダウンロードリンクをメールで送るだけ（再生画面などは作らない）

### なぜ雑か

話者分離は音声のトーン変化ではなく文字起こしの発言区切りだけで簡易判定するため、隣の人の発言を誤って含むことがある。動画の解像度・画質調整はせず入力ファイルのまま出力する。1時間超の録画は処理時間が長くなるため30分以内推奨とスコープを切る。複数人が同時に話すクロストークのシーンはうまく切れない前提。

### 雑な技術スタック候補

Next.js + OpenAI Whisper API + ffmpeg (Node child_process) + Vercel Blob (一時保存) + Resend (メール送信)

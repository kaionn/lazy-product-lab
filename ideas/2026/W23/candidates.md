## 1. DeadlineSpy

- カテゴリ: Browser Extension
- 対象ユーザー: フリーランサー・副業ワーカー
- 一行で: 複数クライアントの締切を1タブで全管理

### 解決する痛み
Notion・Trello・Asana・メールがバラバラで、どのタブにどの締切があるか把握できない。朝「今日何が締め切りだっけ?」をブラウザを開くたびに確認する儀式が発生している。ツールを統合する気力はないが、1 か所で見たい。

### 1 週間で作るならこれ
- 手動でタスク名 + 締切日時を追加できる入力フォーム
- 新規タブを開いた瞬間に残り時間カウントダウン表示
- 48h 以内に迫ったタスクを赤くハイライト
- タスク完了チェックで非表示化
- データは chrome.storage.local に保存 (外部 API 不要)

### なぜ雑か
外部カレンダー連携なし・繰り返しタスクなし・複数デバイス同期なし。ローカル保存のみなのでアカウント不要。UIはCSSなしでもいい。

### 雑な技術スタック候補
Manifest V3 + Vanilla JS + chrome.storage.local (ビルドツール不要、ファイル 5 本以下)

## 2. gitblame-sensei

- カテゴリ: CLI
- 対象ユーザー: 一人開発 or 小チームのエンジニア
- 一行で: git blame を読んで「なぜこう書いた?」をAIが解説

### 解決する痛み
半年前の自分のコードに `git blame` してもコミットメッセージが「fix」「wip」「修正」しか書いてなくて、なぜこのロジックにしたか全く分からない。コードレビューで「これどういう意図?」と聞かれるたびに調査時間が吹き飛ぶ。

### 1 週間で作るならこれ
- 対象ファイル + 行範囲を引数で受け取り `git blame` + `git log -p` を実行
- 取得したコード断片 + コミット差分を Claude API に投げる
- 「当時の変更意図の推測」「現在のコードが何をしているか」「潜在的な地雷」を Markdown で出力
- `--format json` フラグで機械可読出力
- 結果をローカルキャッシュ (`~/.gitblame-sensei/`) に保存して再取得コスト削減

### なぜ雑か
コンテキスト窓を超える巨大ファイルは先頭 200 行だけ送って切り捨て。blame が取れないバイナリファイルはエラーで終了。認証は ANTHROPIC_API_KEY 環境変数のみ。

### 雑な技術スタック候補
Python 3.12 + subprocess + anthropic SDK + diskcache (pip install 2 本だけ)

## 3. MeshiLog

- カテゴリ: モバイル (PWA)
- 対象ユーザー: 自炊する一人暮らし社会人
- 一行で: 食べたものを 3 秒で記録、週の偏り見える化

### 解決する痛み
カロリー管理アプリは入力が重くて続かない。でも「今週ずっと炭水化物しか食ってない気がする」という漠然とした不安は抱えている。MyFitnessPal のような本格的なものは不要で、「今週の食事をざっくり把握したい」だけ。

### 1 週間で作るならこれ
- テキスト or 絵文字でご飯を 1 タップ記録 (「ラーメン」「サラダ」「コンビニ弁当」など)
- AI (Claude API) が記録から「炭水化物多め」「野菜不足」などをゆるく分類
- 週ごとの食事グループ比率をドーナツチャートで表示
- データは IndexedDB に保存 (ログイン不要)
- PWA 化してホーム画面に追加可能

### なぜ雑か
栄養素の正確な計算なし。食材 DB なし。写真認識なし。分類が間違っていてもユーザーが直せない。カロリー表示なし。「ざっくり把握」に振り切る。

### 雑な技術スタック候補
Vite + Preact + Tailwind CSS + IndexedDB + Claude API (ハイカラ不要、3 ファイル構成)

## 1. CO2番長

- カテゴリ: ガジェット
- 対象ユーザー: 換気を忘れて午後に頭が重くなる在宅ワーカー
- 一行で: CO2が上がったらLEDが赤く光って窓を開けさせる

### 解決する痛み
部屋にこもって作業していると CO2 濃度が 1000ppm を超えて眠気・集中力低下が起きる。でも数値は見えないから「なんか今日だるいな」で終わる。換気アプリはスマホを手に取るコストが高い。物理的に目の前で光が変わることで行動につながる。空気質モニターは5000円以上するが、自作なら 2000 円以下で作れる。

### 1 週間で作るならこれ
- ESP32 + SCD40 CO2 センサーで 1 分ごとに CO2・温度・湿度を取得
- CO2 値で RGB LED の色を変化 (緑 <800ppm / 黄 800-1200ppm / 赤 >1200ppm で点滅)
- `http://co2.local/` でブラウザから現在値と過去 24h の折れ線グラフを確認
- しきい値超過時に HTTP Webhook を送信 (IFTTT / スマートスピーカー連携用)
- LittleFS に 24h 分のデータを CSV 保存、ダウンロードボタンあり

### なぜ雑か
安物 SCD40 の精度は ±50ppm なので目安程度。温湿度による自動補正なし。複数部屋管理は複数台買ってください。ケースなしブレッドボード剥き出し。電源は USB 固定でバッテリーなし。LEDs が 1 個なのでリアルタイム数値は画面を見ないと分からない。

### 雑な技術スタック候補
MicroPython + ESP32 + SCD40 + asyncio + utemplate (HTML/JS 埋め込み) + LittleFS

## 2. Focus Anchor

- カテゴリ: 業務ツール
- 対象ユーザー: タスク管理ツールを3日で挫折するリモートエンジニア・フリーランサー
- 一行で: 朝1分・夕1分、MIT宣言と振り返りだけのCLI習慣

### 解決する痛み
朝「今日は○○をやる」と思っても夕方には別の作業に溺れていた、がループする。Notion のタスク管理は項目が多すぎて更新が億劫。「今日の最重要タスク 1 つを宣言して、夕方に振り返る」だけでいいはずなのに、それをやる仕組みが存在しない。カレンダーでも Todoist でもなく、朝夕 2 回 CLI を叩くだけの摩擦ゼロな運用がほしい。

### 1 週間で作るならこれ
- `anchor morning` で今日の MIT (Most Important Task) を入力・ローカル JSON に保存
- `anchor evening` で「達成したか / なぜ達成できなかったか / 明日の MIT」を 3 問対話形式で記録
- `anchor log` で過去 30 日の MIT 達成率を ASCII バーチャートで表示
- 設定した夕方時刻にOS デスクトップ通知で `anchor evening` を促す (cron/launchd)
- `anchor export` で過去 7 日分を Markdown 日報として stdout 出力

### なぜ雑か
通知設定は cron/launchd/systemd への手動登録が必要 (インストールスクリプトで補助するが自動ではない)。タスクの複数登録は非対応で MIT は常に 1 つ。チーム共有・クラウド同期なし。データはローカル JSON ファイルのみでバックアップ手段は自分で用意。Windows の通知は動作未確認。

### 雑な技術スタック候補
Go + cobra + beeep (クロスプラットフォーム通知) + encoding/json + ANSI バーチャート自前実装

## 3. FormSpy

- カテゴリ: SaaS
- 対象ユーザー: GitHub Pages や S3 など静的サイトにお問い合わせフォームを置きたい個人開発者
- 一行で: HTMLのaction属性を1行変えるだけでフォームをメール転送

### 解決する痛み
ポートフォリオサイトや静的ランディングページにお問い合わせフォームを付けたいがバックエンドがない。Netlify Forms は Netlify にデプロイしていないと使えない。Formspree の無料プランは月 50 件まで。Google Forms はデザインが浮いてダサい。AWS Lambda + SES を自前構築するのは大げさすぎる。`<form action="どこか">` の一行だけで動くシンプルなフォームバックエンドが欲しい。

### 1 週間で作るならこれ
- メールアドレスだけでアカウント作成 → フォームエンドポイント URL が即発行
- 静的サイトの `<form action="https://formspy.app/f/abc123" method="POST">` に貼るだけで動く
- 送信データをアカウントのメールアドレスに転送 (1 日 20 件まで無料)
- ダッシュボードで送信履歴 (日付・送信元 IP・フィールド内容) を一覧確認
- honeypot フィールドによる基本的なスパムフィルター (`<input name="_honeypot" hidden>`)

### なぜ雑か
スパム対策は honeypot のみで reCAPTCHA 未対応。ファイル添付非対応。Webhook への転送なし (メール転送のみ)。送信後のリダイレクト先 URL はフォームの hidden フィールドで指定 (カスタムサンキューページは自前で)。CORS ヘッダーはワイルドカードで全ドメイン許可のザル設定。

### 雑な技術スタック候補
FastAPI + SQLite + Mailgun API (無料枠 1000 通/月) + Jinja2 + Railway 無料枠でホスト

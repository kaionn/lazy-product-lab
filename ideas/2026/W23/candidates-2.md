## 1. StandupDraft

- カテゴリ: Web (SaaS)
- 対象ユーザー: リモートチームのエンジニア・デザイナー
- 一行で: 3フィールド埋めるだけで今日のスタンダップ完成

### 解決する痛み
毎朝 Slack に「昨日やったこと / 今日やること / ブロッカー」を書くとき、頭が起きてなくて5分かかる。書き方がバラバラでチームの読みやすさも統一されない。「ちゃんと書かなきゃ」というプレッシャーで余計に詰まる。Notion の daily note に書いてから Slack にコピペする二度手間もある。

### 1 週間で作るならこれ
- 「昨日」「今日」「ブロッカー」3 欄のシンプルな入力フォーム
- Slack 用・ Notion 用・プレーンテキスト用の 3 フォーマットでワンクリックコピー
- 入力内容を localStorage に保存し、翌朝「昨日」欄に前日の「今日」を自動セット
- チーム共有テンプレート (URL パラメータでフォーマット共有)
- カレンダー形式で過去スタンダップ履歴をざっくり閲覧

### なぜ雑か
スタンダップを Slack に直接投稿する機能なし。認証なし。複数プロジェクト管理なし。「コピペして貼る」を最終ゴールにして、OAuth 周りを全部省略する。

### 雑な技術スタック候補
Next.js 15 + Tailwind CSS + localStorage のみ (DB・認証・バックエンド不要、Vercel 無料枠でデプロイ)

## 2. RetroBot

- カテゴリ: Bot (Slack)
- 対象ユーザー: スクラムチームのスクラムマスター・チームリーダー
- 一行で: 週次レトロをSlackだけで回収・まとめるbot

### 解決する痛み
週次レトロのためだけに全員がミーティングに集まるのが重い。Miro や FigJam を開く手順でさらに離脱者が出る。ファシリテーターが「何かありますか?」と静寂に耐える時間がつらい。レトロの結果がどこかに埋もれてアクションが追われない。

### 1 週間で作るならこれ
- Slack の `/retro start` コマンドで DM 収集開始
- 各メンバーに「Good / Bad / Try をそれぞれ書いてください」と DM 送信
- 全員回答 or タイムアウトで自動集計しチャンネルに投稿
- KPT 形式でカテゴリ分けして Slack メッセージとして整形
- アクションアイテムとして挙がった項目を次週のリマインダーとして自動再送

### なぜ雑か
参加者の回答を AI が分析したり自動カテゴリ分けしたりしない。テキストの全文をそのまままとめるだけ。Slack ワークスペースをまたいだ管理なし。1 ワークスペース・1 チャンネル前提のハードコード実装で OK。

### 雑な技術スタック候補
Python 3.12 + slack-bolt + SQLite (セッション管理用) + Railway 無料枠でデプロイ

## 3. RegexDojo

- カテゴリ: ゲーム (ブラウザ)
- 対象ユーザー: 正規表現が苦手 or 練習したいエンジニア
- 一行で: 文字列パズルを正規表現で解くだけの道場ゲーム

### 解決する痛み
正規表現は「なんとなくわかる」状態が何年も続く。regex101.com で都度調べるが、覚えられない。ドキュメントは読んでも退屈で頭に入らない。「ゲーム感覚で覚えられるサービスがあれば…」と思いつつ Duolingo みたいな大掛かりなものを想像して諦める。

### 1 週間で作るならこれ
- 「この文字列にマッチさせろ (かつこの文字列にはマッチさせるな)」形式のパズル 30 問
- ブラウザ上で正規表現を入力すると即時にマッチ判定 (緑/赤で可視化)
- 全問正解で次の問題に進む線形ステージ構成
- 各問題にヒントボタン (1 回クリックすると使える構文のヒントが出る)
- クリア時間をローカルで記録してタイムアタック要素を追加

### なぜ雑か
ユーザーアカウントなし。進捗はローカルストレージのみ。問題はハードコードで外部 DB なし。難易度バランス調整は初回リリースでは「なんとなく」。モバイル最適化なし。

### 雑な技術スタック候補
Vite + Vanilla TypeScript + CSS のみ (フレームワーク不要、静的ファイルとして GitHub Pages にデプロイ)

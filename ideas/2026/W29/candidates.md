## 1. ci-digest

- カテゴリ: Bot (GitHub App)
- 対象ユーザー: CI ログ解読に時間を溶かしている個人・小チーム開発者
- 一行で: CI 失敗ログを AI が 3 行に圧縮して PR にコメント

### 解決する痛み

GitHub Actions の CI が落ちるたびに、ANSI エスケープだらけの数百行ログをスクロールして「どの行でなぜ落ちたか」を探す作業が地味につらい。エラー行を発見しても「なぜそうなったか」の文脈がなく、Stack Overflow を漁るのに 20 分溶かすことが週に何度もある。「ログを貼れば AI が読んでくれる」のに、わざわざコピペして ChatGPT に投げるのも面倒だ。

### 1 週間で作るならこれ

- `check_run.completed` イベントを受け取る GitHub App (Webhook) を Vercel Serverless で立てる
- GitHub API でジョブログを取得（末尾 300 行のみ）し Claude API に投げる
- 「原因・該当ファイル・提案 Fix」の 3 項目を日本語で返させ PR コメントとして自動投稿
- 同じワークフローが連続 3 回以上失敗したら「環境問題の可能性あり」バッジをつける
- `.ci-digest.yml` にコメントを投稿しない CI ジョブ名の除外リスト設定

### なぜ雑か

ログが 300 行超えたら末尾だけ食わせるので前半のエラーは見落とす。マトリクスビルドの並列ジョブは最初に完了したジョブしか解析しない。日本語固定でロケール設定なし。GitHub Enterprise 非対応。API レートリミットに当たったら黙ってスキップするだけ。

### 雑な技術スタック候補

Node.js + @octokit/webhooks + Vercel Serverless Functions + Claude API (claude-haiku-4-5)、GitHub Apps として手動インストール

## 2. grave

- カテゴリ: CLI
- 対象ユーザー: ローカルブランチが溜まりすぎて `git branch` が 80 行になっている開発者
- 一行で: git ブランチ墓地を一覧して古いやつを一括掃除する

### 解決する痛み

`git branch` を実行するたびに 2 年前のブランチが大量に並んで目が泳ぐ。`git branch -d` は 1 本ずつだし、「まだ必要だったりしないか？」という不安で削除ボタンを押せない。main にマージ済みかどうかを確認するコマンドも毎回ググっている。気づくと 3 ヶ月前の feature ブランチが 50 本眠っており、誰も消せない墓地になっている。

### 1 週間で作るならこれ

- `grave` で全ローカルブランチを「最終コミット日 / マージ済みフラグ / 著者名」付きで表形式に一覧表示
- 30 日未更新は黄色、90 日以上は赤でハイライト
- `grave --delete-merged` で main/master にマージ済みブランチをドライランしてから `y/N` 確認で一括削除
- `grave --remote` でリモートブランチも含めて表示（削除対象には含めない：安全のため）
- `grave --export branches.csv` でブランチ一覧を CSV エクスポート（スプレッドシートで整理できる）

### なぜ雑か

マージ判定は `git branch --merged main` のみで、squash merge や rebase merge は「未マージ」扱いになる（false negative 多め）。リモートへの削除は未実装。ブランチ名に日本語が含まれると表示幅ズレ。Windows (Git Bash 以外) は未テスト。

### 雑な技術スタック候補

Go 単一バイナリ (cobra + go-git + tablewriter + color)、`brew install` または `go install` で配布

## 3. hotkey-gym

- カテゴリ: 学習ツール (Web)
- 対象ユーザー: マウスを捨ててキーボード職人になりたいエンジニア・デザイナー
- 一行で: アプリ別ショートカットキーを毎日 5 分で叩き込む反射道場

### 解決する痛み

VS Code や Vim のショートカットを「覚えたい」と思いながら、実際に使う場面では思い出せずマウスに逃げてしまう。チートシートを印刷して机に貼っても眺めるだけで身にならない。読む勉強ではなく「手が覚える」ための反復練習ツールが意外と存在しない。「今日 5 分だけやろう」と思えるちょうどよい粒度の練習場が欲しい。

### 1 週間で作るならこれ

- アプリを選ぶ（VS Code / Vim / Mac システム / Figma の 4 択、各 50 問）
- 「ファイルを保存する」「選択行をコメントアウト」などのタスク説明を表示
- ユーザーが実際にキーを押すと `keydown` イベントで照合、正解なら即次の問題へ
- 連続正解数（streak）と平均反応速度をセッション中にリアルタイム表示
- 苦手キーは自動的に出現頻度を上げる（SM-2 の雑い版：間違えたら3問後に再出題）

### なぜ雑か

問題は JSON ハードコードで追加・編集 UI なし。OS によってキーバインドが違う問題（Mac/Win）は Mac 固定で逃げる。Vim のモード遷移など複合操作（`gg` や `dw`）は複数キーの照合精度が甘い。問題数は各アプリ 50 問固定でローテーション。

### 雑な技術スタック候補

Vite + Vanilla TS + localStorage（正答率保存）、GitHub Pages で無料ホスト・単一 HTML にビルド可能

## 1. RegexDojo

- カテゴリ: 学習ツール
- 対象ユーザー: Regex を業務で使うが自信がないエンジニア・データエンジニア
- 一行で: 自分のログを教材に Regex を実地練習するのだ

### 解決する痛み
regex101.com みたいな練習サイトは「メアドにマッチ」「郵便番号を抽出」など架空のサンプルばかりで、実際に Nginx ログや業務 CSV を扱う場面で使えるパターンが書けない。「何を書けばいいか分からない」状態では練習にならないし、業務でいざ使うと毎回 Stack Overflow に頼る。

### 1 週間で作るならこれ
- ローカルのテキストファイル・ログをドラッグ&ドロップで読み込み
- お題を 10 問自動生成（「404 のある行を全部抽出」「IP アドレスだけ取り出す」など）
- Regex 入力欄でリアルタイムハイライト表示
- 正解判定（期待マッチ数との比較）
- 不正解時の解説と改善パターン例を表示

### なぜ雑か
お題生成は固定ルールテンプレートで内蔵（LLM なし）。Regex 構文エラーは try/catch でブラウザがよろしくやる。lookbehind・POSIX 拡張など高度な構文は採点対象外。アップロードしたファイルはサーバーに送らず DOM 内で完結するが「セキュアです」とは保証しない。

### 雑な技術スタック候補
Vanilla JS + File API + ブラウザネイティブ RegExp → GitHub Pages で静的ホスト（バックエンドなし）

## 2. ジョブシャドウ日誌

- カテゴリ: Web
- 対象ユーザー: 新入社員・インターン・ジョブチェンジ中の見習い
- 一行で: 見て学んだことを 30 秒で記録する職人見習い日誌

### 解決する痛み
新しい職場・技術を学ぶとき「見ているだけ」では記憶に残らない。でも Notion に毎日書く気力はない。週次 1on1 で「最近何を学びましたか?」と聞かれたとき「えーと…」となり、成長を言語化できず評価されない。日記アプリは自由すぎて書けないし、業務ログアプリは重すぎる。

### 1 週間で作るならこれ
- 「日付・観察対象・行動・#1 の学び」の 3 フィールドだけのミニフォーム
- カレンダーで記録した日をヒートマップ表示（継続の可視化）
- タグ付けで「技術」「コミュニケーション」「業務プロセス」に分類
- 月次サマリー（よく出るタグ Top3・最多観察対象）を自動生成
- CSV エクスポートで 1on1 や振り返りの資料に貼り付け

### なぜ雑か
認証は localStorage のみなのでブラウザをまたいで使えない。デバイス間同期なし。タグは手打ちテキストで正規化なし（「コミュニケーション」と「コミュニケーション 」が別タグになる）。画像・スクリーンショット添付なし。

### 雑な技術スタック候補
Next.js + localStorage + Tailwind CSS → Vercel 無料枠でホスト

## 3. SSH Buddy

- カテゴリ: CLI
- 対象ユーザー: 複数サーバーを管理するインフラエンジニア・SRE
- 一行で: 全 SSH セッションのコマンド履歴をサーバー横断で検索

### 解決する痛み
「あの本番サーバーで nginx のログをどうやって絞り込んだっけ？」が思い出せない。`.bash_history` はサーバーごとに分断されていて上書きされ、Ctrl+R は現在のセッションしか探せない。チームの Confluence や Notion に残すほどでもない一時コマンドほど後で忘れ、同じ試行錯誤を繰り返す。

### 1 週間で作るならこれ
- `.bashrc` に 1 行追記するだけで全 SSH 先のコマンドをホスト名+タイムスタンプ付きで収集
- `sshbuddy search <keyword>` でサーバー横断全文検索
- `sshbuddy top` でよく使うコマンド Top20 をホスト別に表示
- `sshbuddy export` でコマンドチートシート Markdown を生成
- ホスト名・日付でフィルタ

### なぜ雑か
収集は bash_preexec hook 依存（zsh は別途設定が必要で手順書に逃げる）。パスワードやトークンが含まれるコマンドも容赦なく保存する。暗号化なし。リモートから収集を Pull する仕組みはなくローカル DB に蓄積するだけ。

### 雑な技術スタック候補
Python + Click + SQLite（~/.sshbuddy.db） + bash_preexec.sh 同梱 → pip install で配布

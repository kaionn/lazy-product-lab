## 1. Micro-changelog

- カテゴリ: SaaS
- 対象ユーザー: ユーザー数 100 人以下のインディー開発者・ソロプレナー
- 一行で: Markdown 貼るだけで購読者にメール配信する changelog サービス

### 解決する痛み

プロダクトを更新してもユーザーに伝える仕組みがない。Ghost/Substack はオーバーキルで設定に 1 日かかる。GitHub Releases はエンジニア向けすぎて一般ユーザーには届かない。「v1.2 のバグ直したよ」を伝えるためだけに決済・テンプレート・配信インフラを全部自前で実装したくない。MailChimp を立ち上げるには大げさすぎる温度感。

### 1 週間で作るならこれ

- プロジェクト登録で `yourapp.microchangelog.io` のパブリックページを払い出し
- Web エディタでエントリを投稿（Markdown + バージョン番号 + 任意タグ）
- パブリックページに設置される購読フォームにメールアドレスを登録する仕組み
- 投稿トリガーで購読者全員に HTML メールを自動送信（SendGrid 無料枠）
- RSS フィード自動生成（`/feed.xml`）でリーダー購読も可能

### なぜ雑か

テンプレートは 1 種類固定でカスタマイズ不可。カスタムドメインなし。SendGrid 無料枠（100 通/日）の上限を超えたら翌日に配信遅延。購読解除フローは SendGrid 標準リンクに丸投げ。画像アップロードなし、URL リンクのみ。

### 雑な技術スタック候補

Next.js + Supabase (DB + Auth) + SendGrid 無料枠 + Vercel デプロイ

## 2. レシートポイ

- カテゴリ: モバイル
- 対象ユーザー: 「いつか家計管理ちゃんとやろう」と思い続けているカップル・一人暮らし社会人
- 一行で: レシートを撮るだけで食費・外食・日用品が月次でわかるのだ

### 解決する痛み

マネーフォワードは口座連携の設定で離脱する。現金払いが多い生活（コンビニ・スーパー・居酒屋）はどの自動連携ツールも補足できない。家計アプリで毎回手入力する習慣が続かない。「だいたい食費と外食でいくらかかってるか」だけ知れれば十分なのに、機能が多すぎて使いこなせない感じがつらい。

### 1 週間で作るならこれ

- カメラでレシートを撮影して Google Vision API で OCR（合計金額・店名・日付を抽出）
- 店名から自動カテゴリ推定（スーパー → 食費、コンビニ → 日用品、居酒屋 → 外食 etc）
- カテゴリを 1 タップ修正できる確認画面（推定ミスは手で直す）
- 当月の合計をカテゴリ別円グラフで表示、月初にリセット
- データは端末ローカルの SQLite に保存（クラウド同期なし）

### なぜ雑か

OCR が読み取れないレシートは手入力になる（サーマル紙が薄いと失敗しやすい）。外貨・英語レシートは対象外。家族間のデータ共有機能なし。銀行口座・クレカとの自動連携なし。月別比較グラフは未実装。

### 雑な技術スタック候補

React Native (Expo) + expo-camera + Google Vision API + expo-sqlite、TestFlight / Expo Go で配布

## 3. MeetingBurn

- カテゴリ: 業務ツール
- 対象ユーザー: 「この会議、本当に必要？」と感じているチームリーダー・スクラムマスター・エンジニア
- 一行で: 会議中に人件費をリアルタイムでカウントして無駄を可視化するのだ

### 解決する痛み

8 人 × 1 時間の会議は 8 人時が燃えているが、誰もそれを数字で実感しない。「無駄な会議を減らそう」と口で言っても変わらない。コストが画面に出ていれば「15 分で切り上げよう」「この決定は非同期でいいな」が自然に起きる。会議コスト可視化ツールの先行例はあるが、URL をシェアするだけで参加者全員がリアルタイムで同じカウンターを見られるものがない。

### 1 週間で作るならこれ

- 参加人数と平均時給（プリセット: 3,000 / 5,000 / 8,000 円 or カスタム入力）を設定してスタート
- 「現在のコスト」が 1 秒ごとにリアルタイム更新される画面
- URL をコピーしてチャットに貼ると参加者全員が同じカウンターを共有（Partykit WebSocket）
- 終了時に合計コスト・経過時間・「缶コーヒー ○ 本分」換算をまとめて表示
- 過去 5 会議分のコスト履歴を localStorage に保存して確認できる

### なぜ雑か

参加者全員が同じ時給前提で個別設定なし。認証なし（URL を知っていれば誰でも操作できる）。会議終了後のレポート出力なし。Google Calendar / Zoom との連携なし。Partykit 無料枠を超えるような大規模利用は想定しない。

### 雑な技術スタック候補

Vanilla JS + Partykit (WebSocket 無料枠) + Vercel (静的ホスト)、依存関係を最小限にする

## 1. dep-why

- カテゴリ: CLI
- 対象ユーザー: 「なぜこのパッケージ入れたんだっけ」となるソロ/小チーム開発者
- 一行で: package.json の依存を入れた理由を git から掘り出す

### 解決する痛み

`package.json` や `requirements.txt` を眺めて「`left-pad` ってなんで入ってるの?」と困る瞬間が週に何度もある。コードを grep しても直接使われていないトランジティブ依存か、もう消してもいいコードか判断できない。git log を手で掘るのは面倒すぎる。

### 1 週間で作るならこれ

- `dep-why <パッケージ名>` で該当パッケージを追加したコミットを git log から検索
- コミットメッセージ + diff の前後 10 行を表示
- `--json` フラグで機械読み取り可能な出力
- npm/pip/cargo の 3 形式のロックファイルに対応
- `dep-why --all` で未使用っぽい依存を一覧 (import grep ベースの雑判定)

### なぜ雑か

モノレポ非対応。ロックファイルが壊れていたら動かない。「未使用っぽい」判定は単純 grep なので動的 import や barrel export を見落とす。エラーメッセージは最低限。

### 雑な技術スタック候補

Node.js + simple-git + chalk + commander.js、npm publish で配布

## 2. Tab Time Machine

- カテゴリ: Browser Extension
- 対象ユーザー: タブを誤って閉じて泣くリサーチャー・学生
- 一行で: 閉じたタブを 30 日間こっそり覚えておく拡張

### 解決する痛み

ブラウザの「最近閉じたタブ」はセッションをまたぐと消える。調査中に誤って閉じたタブを「あれなんのサイトだっけ」と思い出せず 20 分溶かした経験は誰でもある。履歴から探そうにもタイトルを覚えていないと見つからない。

### 1 週間で作るならこれ

- タブを閉じるたびに URL・タイトル・閉じた時刻を localStorage に保存 (上限 300 件)
- ポップアップに検索ボックス + 時系列リストを表示
- クリックで該当 URL を新タブで開く
- 30 日以上古いエントリは自動削除
- ドメイン別にグルーピングして表示するビュー

### なぜ雑か

Chrome 専用 (Manifest V3)。デバイス間同期なし。シークレットウィンドウは無視。画像サムネイルなし。localStorage なので 5MB 超えたら古いものから問答無用で削除。

### 雑な技術スタック候補

Vanilla JS + Chrome Extension Manifest V3 + localStorage、ビルド不要でそのまま zip 配布

## 3. Shell Escape

- カテゴリ: ゲーム (Web)
- 対象ユーザー: bash を覚えたいけど写経が続かないプログラミング入門者
- 一行で: 本物のコマンドを打って脱出するパズルゲーム

### 解決する痛み

`ls`・`grep`・`find`・`pipe` の使い方を覚えたいが、チュートリアルを読むだけでは定着しない。手を動かそうとしても「練習用のファイルを用意する」ハードルで挫折する。ゲームっぽい文脈があれば打ち込みやすい。

### 1 週間で作るならこれ

- ブラウザ内の疑似ターミナル (xterm.js) で実際に bash コマンドを入力
- 15 ステージ: 「怪しいファイルを探せ」「ログから IP を抽出せよ」など
- 各ステージは期待出力と照合して正解判定
- ヒント表示ボタン (3 回まで)
- クリア時間とコマンド数でスコア表示

### なぜ雑か

バックエンドなし・全クライアントサイド。疑似 FS はメモリ上の JS オブジェクトなので本物の bash ではない (`grep` の正規表現の一部は未実装)。ステージはハードコードされた JSON。スコアはローカルだけで共有不可。

### 雑な技術スタック候補

Vite + xterm.js + ハードコード JSON ステージ定義、GitHub Pages で無料ホスト

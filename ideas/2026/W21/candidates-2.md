## 1. Session Scribe

- カテゴリ: Bot (Discord)
- 対象ユーザー: TRPG セッションを Discord テキストで遊ぶオタク
- 一行で: 前回のあらすじを Bot が自動生成する

### 解決する痛み

Discord のテキスト TRPG はセッションをまたぐと「前回どこまでやったっけ?」が毎回発生する。ログを遡るのは億劫で、ゲームマスターが毎回手動で要約を書くのは準備コストが高い。前回あらすじを読み上げる 5 分が地味に参加者の集中を削ぐ。

### 1 週間で作るならこれ

- `/recap [チャンネル名] [件数]` で指定チャンネルの直近 N メッセージを取得
- Claude API で「TRPG セッションのあらすじ」フォーマットに要約して投稿
- `/recap --since 2026-05-10` で日付指定取得
- 要約を専用ログチャンネルに自動 pin
- `/recap --characters` で登場 NPC・PC の名前リストを抽出

### なぜ雑か

Bot に読める公開チャンネルのみ対応。長すぎるログは先頭 200 メッセージで打ち切り。画像・音声の内容は無視。複数サーバー対応なし・ローカル 1 インスタンス前提。レート制限は適当。

### 雑な技術スタック候補

Python + discord.py + Anthropic SDK (claude-haiku-4-5)、Fly.io の無料枠で常時起動

## 2. RegexRoulette

- カテゴリ: 学習ツール (Web)
- 対象ユーザー: 正規表現の書き方を身につけたいプログラミング初中級者
- 一行で: 30 秒で正規表現を書いてパターンを当てるゲーム

### 解決する痛み

正規表現は「必要なときにググって貼るもの」になりがちで、自分で書けるようにならない。チュートリアルを読んでも手を動かすまでの摩擦が高い。実際に書いて即フィードバックを受けるループが一番身につくのに、それだけに特化したツールがほぼない。

### 1 週間で作るならこれ

- 30 秒タイムアタック: お題テキストが表示され、マッチさせる正規表現を入力
- リアルタイムハイライト: 入力と同時に対象テキスト上でマッチ箇所を色表示
- 難易度 3 段階 (基本文字クラス / 量指定子 / 先読み後読み)
- クリア時間 + 試行回数でスコア計算、ローカル localStorage にランキング保存
- 不正解時に「別解例」をワンクリックで表示

### なぜ雑か

問題は全てハードコード JSON で 50 問のみ。フラグ (`/g`, `/m`, `/s`) は問題側で固定なのでユーザーが選べない。スコアはローカルのみ・共有不可。モバイルレイアウト未対応。PCRE2 限定でエンジン差異は無視。

### 雑な技術スタック候補

Vite + Vanilla TS + CSS Modules、GitHub Pages で無料ホスト・ビルド 1 コマンド

## 3. MeetingCost.live

- カテゴリ: 業務ツール (Web)
- 対象ユーザー: 会議が多い会社員・マネージャー
- 一行で: 今この会議に何円かかってるかリアルタイム表示

### 解決する痛み

「この定例、本当に必要?」と思いながら参加し続けるのに、コストが可視化されないので意思決定できない。1 時間 × 10 人 × 平均時給 5,000 円 = 5 万円、という計算は頭でわかっていても実感がない。会議開始時にタイマーを回してコストを積算表示するだけで「もう終わりにしよう」の合意が取りやすくなる。

### 1 週間で作るならこれ

- 参加人数 + 平均時給（円/時）を入力してスタートボタン
- 経過時間と累積コストをリアルタイムで大きく表示（円・ドル切替）
- 「1 分あたり ○○ 円」を小さく常時表示
- 会議終了ボタンで「この会議のコスト: ○○ 円（= コーヒー ○ 杯分）」を表示
- URL パラメータで設定を共有 (`?n=8&rate=5000` でプリセット)

### なぜ雑か

認証なし・保存なし・純フロントエンド。時給は参加者全員同一単価で計算。タブを閉じたらリセット。消費税・福利厚生費は無視。スマホ縦向きだとレイアウトが崩れる可能性あり。

### 雑な技術スタック候補

Vite + React + useInterval フック 1 本のみ、Cloudflare Pages で無料ホスト

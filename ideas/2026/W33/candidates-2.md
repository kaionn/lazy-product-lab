## 1. アフタートーク秒速メール

- カテゴリ: Web (AI ツール)
- 対象ユーザー: 商談・営業電話の後にお礼メールを書くのが面倒でつい後回しにするフリーランス・営業担当
- 一行で: 通話後の箇条書きメモを貼るだけでお礼メールの下書きが30秒で出てくるのだ

### 解決する痛み

商談やクライアント電話の直後は話した内容の熱量が高いのに、丁寧なお礼メールを一から書く気力がなくて後回しにしてしまう。気づけば翌日になり「今更感」が出て結局送りそびれる、あるいは味気ないテンプレをそのまま使い回して手抜き感が伝わる。毎回ゼロから文面を組み立てる時間はないが、通話中にとった箇条書きメモを貼るだけで丁寧語の下書きが秒で出てくれば十分。

### 1 週間で作るならこれ

- テキストエリアに通話メモ（箇条書きでOK）を貼り付けるだけの1画面
- 宛先との関係性（初回商談/既存クライアント/紹介経由）をラジオボタンで選択
- メモと関係性をOpenAI APIに渡してお礼メールの文面を生成
- 生成結果はコピー用ボタン付きでそのまま表示、編集はブラウザ上で直接
- 直近5件の生成履歴をブラウザのlocalStorageに保持するだけ（サーバー側DBは持たない）

### なぜ雑か

ユーザーアカウントは作らず、生成履歴は端末のlocalStorageのみで別端末からは見えない。メール送信機能は持たず「コピーして自分のメーラーに貼る」までがスコープ。フォーマル度合いを調整するスライダーなどのトーン調整機能は作らない。対応言語は日本語のみ。

### 雑な技術スタック候補

Next.js + OpenAI API + localStorage + Vercel

## 2. ライセンス地雷探知機

- カテゴリ: CLI
- 対象ユーザー: 個人開発者・受託エンジニアで依存パッケージのライセンスを毎回手動確認していない人
- 一行で: package.jsonを指定するだけでGPL系など商用利用が怪しいライセンスの依存だけ一覧で教えてくれるのだ

### 解決する痛み

受託案件やSaaSに組み込むnpmパッケージを増やすたびに本来は各依存のライセンスを確認すべきだが、正直ほとんどの現場でやられていない。ある日クライアントの法務チェックでGPL系依存が見つかり、代替パッケージへの置き換えに丸一日潰れる、という事故が起きがち。license-checker系のツールは存在するが設定項目が多く結局使われないまま放置される。「危険なライセンスだけ教えて」の一発コマンドが欲しい。

### 1 週間で作るならこれ

- package.jsonのdependencies/devDependenciesを読み込みnode_modules配下の各パッケージのlicenseフィールドを収集
- GPL/AGPL/LGPL/SSPLなど「要注意リスト」に該当するものだけを赤字でターミナルに一覧表示
- MIT/Apache/BSDなど安全リストはデフォルトで非表示（`--all`オプションで全件表示に切り替え）
- 検出結果をJSON/Markdownでエクスポートするオプション
- licenseフィールドが存在しない・不明なパッケージは別枠で警告表示

### なぜ雑か

ライセンス判定はpackage.jsonのlicenseフィールドを信じるだけで、LICENSEファイル本文までは読まないため誤記や二重ライセンスは検知漏れになりうる。npm限定でPython・Rubyなど他言語のパッケージマネージャには対応しない。要注意リストはハードコードで、法務的な正確性を保証するものではない旨を明記するだけで済ませる。モノレポのworkspace横断チェックはしない。

### 雑な技術スタック候補

Node.js CLI + commander.js + fs (node_modules走査) + chalk

## 3. 質問迷子救済くん

- カテゴリ: Bot (Slack)
- 対象ユーザー: リモートチームでSlackに投げた質問が埋もれて返信が来ないまま流れていくメンバー
- 一行で: 質問っぽいメッセージが半日返信なしだと毎朝まとめて「まだ拾われてません」と教えてくれるのだ

### 解決する痛み

質問を投稿しても既読スルーされたまま話題が流れ、数日後に「あれどうなりましたか」と聞き直すのが気まずい。逆に聞かれた側も忙しさで悪気なく見落として放置してしまうことも多い。リマインダーを質問ごとに手動でセットするのは面倒だし、`@here`で急かすと角が立つ。誰も名指しで責めずに「拾われていない質問」だけをそっと可視化したい。

### 1 週間で作るならこれ

- 監視対象チャンネルを`/qwatch add #channel`で登録
- メッセージ末尾が「？」「?」「〜でしょうか」等の疑問形で終わるものを質問候補として記録
- 投稿から12時間以内にスレッド内で誰かが返信していれば候補から除外
- 未返信のまま12時間経過した質問を、毎朝9時にダイジェストとして投稿者本人にDMでまとめ送信
- ダイジェスト内のリンクをクリックすると該当スレッドへ直接ジャンプ

### なぜ雑か

疑問形の判定は文末の記号・語尾に頼った簡易ルールのみで、返信不要な相談メッセージまで拾う誤検知は放置する。スレッド外の絵文字リアクションは「返信済み」とみなさない。既読・未読の区別はしない。DMは投稿者本人にのみ送り、聞かれた相手を名指しで急かす機能は作らない。

### 雑な技術スタック候補

Slack Bolt (Node.js) + Slack Events API + node-cron + Slackスレッド機能

## 1. ゴミ出し番地くん

- カテゴリ: Bot (LINE)
- 対象ユーザー: 自治体のゴミ出しルールを覚えられない一人暮らし・引っ越したばかりの人
- 一行で: 住んでる地域のルールを登録するだけで今日出せるゴミの種類を毎朝LINEで教えてくれるのだ

### 解決する痛み

引っ越し直後や分別ルールが複雑な自治体だと「今日は何ゴミの日だっけ」を毎回市区町村サイトのPDFで確認する羽目になる。前夜に出し忘れて次の収集日まで1週間ゴミが溜まる一方、逆に間違った種類を出してしまい回収されず玄関先に放置される気まずさもある。カレンダーアプリに手動転記するのも面倒で三日坊主になる。とにかく毎朝勝手に教えてほしい。

### 1 週間で作るならこれ

- LINE公式アカウントを友だち追加した状態で「地域名＋曜日ごとのゴミ種別」をトーク形式で初期登録
- 登録内容はスプレッドシート（Supabaseでも可）に保存し、燃える/燃えない/資源ごみを曜日にひも付け
- 毎朝7時にcronジョブがその日のゴミ種別をLINE Messaging APIでプッシュ通知
- 出す物がない日は通知をスキップする設定をトグル可能
- 祝日による収集日振替には対応しない旨をFAQに明示するだけで済ませる

### なぜ雑か

自治体公式データとの自動連携はせず、ユーザーが手入力したルールをそのまま信じる。祝日による収集日振替や臨時収集には対応しない（通知が外れることがある）。地域は市区町村名をフリーテキストで受けるだけで住所からの自動判定はしない。複数世帯・法人利用は想定しない。

### 雑な技術スタック候補

LINE Messaging API + Google Apps Script（cronトリガー） + スプレッドシートDB

## 2. 洗濯終わったよセンサー

- カテゴリ: ガジェット
- 対象ユーザー: 洗濯機を回したまま作業に没頭して取り出し忘れる在宅ワーカー
- 一行で: 洗濯機に振動センサーを貼るだけで運転音が止まった瞬間LINEで教えてくれるのだ

### 解決する痛み

洗濯を回した後に集中して作業していると終了に気づかず、数時間放置して生乾き臭がついてしまい洗い直すはめになる。洗濯機のブザーは家の奥の部屋やイヤホンをしていると聞こえない。スマホ連携対応の洗濯機に買い替えるほどではないが「終わったら一言教えてほしい」だけを解決したい。

### 1 週間で作るならこれ

- ESP32 ＋ 振動センサー（SW-420）を洗濯機の蓋か側面に養生テープで固定
- 振動値を2秒おきにサンプリングし、直近60秒の振動平均が閾値を下回ったら「停止」と判定
- 停止検知後3分間再び振動がなければ「洗濯完了」とみなしLINE Messaging APIで通知
- 洗濯開始時刻も記録して通知文に「洗濯時間◯分でした」を添える
- Wi-Fi設定はWiFiManagerライブラリのブラウザ設定画面で行う

### なぜ雑か

振動閾値は洗濯機の機種ごとに手動調整が必要でキャリブレーション機能はなし。乾燥機能付き機種だと乾燥終了を待たず洗濯終了だけ検知してしまう可能性がある。地震や来客のドア開閉による誤検知の除去ロジックはなし。電源はモバイルバッテリー直挿しでケースは作らない。

### 雑な技術スタック候補

ESP32 + SW-420振動センサー + Arduino IDE + WiFiManager + LINE Messaging API

## 3. シークレット掘り起こしくん

- カテゴリ: CLI
- 対象ユーザー: 個人開発者・小規模チームでgitleaks等の導入まで手が回らない人
- 一行で: リポジトリを指定するだけでコミット履歴に埋もれたAPIキーらしき文字列を洗い出してくれるのだ

### 解決する痛み

個人開発だと「.envをうっかりコミットして、後で気づいてhistory rewriteした」経験は誰にでもある。だが本当に消えたのか、他のコミットにも似た文字列が残っていないか確認する手段がない。GitHubにpushする直前に毎回全diffを目視で読むのは限界がある。かといって本格的なセキュリティツールを導入するほどの規模でもなく、`git log`を舐めて怪しい文字列を一覧表示するだけの軽量チェッカーが欲しい。

### 1 週間で作るならこれ

- 指定したローカルリポジトリの全コミット差分をgit logコマンドで走査
- AWSキー・Slackトークン・汎用APIキーっぽい文字列（正規表現パターン十数種）にマッチした行を抽出
- マッチ箇所をコミットハッシュ・ファイル名・行番号付きでターミナルにリスト表示
- `--since`オプションで直近N日分のコミットだけに絞れる
- 検出結果をMarkdownレポートとして書き出すオプション

### なぜ雑か

正規表現ベースなので誤検知（ダミー文字列やテスト用のfakeキー）も大量に拾う。エントロピー計算による精度向上はしない。検出後にhistory書き換えやキー失効を行う機能は持たず、あくまで「見つけるだけ」。プライベートリポジトリのローカルクローンのみ想定でGitHub Organizationの一括スキャンは対象外。

### 雑な技術スタック候補

Node.js CLI + simple-git + 正規表現パターン集（gitleaksのルールを参考） + commander.js
